## Amazon Mechanical Turk 将停止接受新客户
- source: TechCrunch
- date: 2026-07-05
- category: 应用/产业,生态
- url: https://techcrunch.com/2026/07/05/amazon-will-stop-accepting-new-customers-for-mechanical-turk/
- summary: Amazon Mechanical Turk 将于 7 月 30 日停止接受新客户，象征早期人类标注市场进入收缩阶段。
- detail: |

## arXiv 论文提出 LLM 推荐系统长度偏差缓解框架 LBR
- source: arXiv
- date: 2026-07-05
- category: 论文,应用/产业
- url: https://arxiv.org/abs/2607.04270
- summary: LBR 论文指出 LLM 推荐系统会受到物品描述长度影响，并提出轻量校准方法降低排序偏差。
- detail: |
    arXiv 论文《LBR: Towards Mitigating Length Bias in Large Language Models for Recommendation》指出，物品文本描述长度会影响 LLM 推荐系统的注意力和打分。

    论文提出 Length Bias Reduction，用长度感知注意力校准等方式降低偏差。对电商、内容平台和广告推荐而言，这类方法有助于把 LLM 推荐从原型推向更可控的生产系统。

## arXiv 论文研究 LLM 不确定性与拒答机制
- source: arXiv
- date: 2026-07-05
- category: 论文,安全
- url: https://arxiv.org/abs/2607.04430
- summary: 论文提出面向 LLM 问答系统的不确定性感知拒答方法，试图减少幻觉和错答风险。
- detail: |
    arXiv 论文《Uncertainty-Aware Abstention in Large Language Models with Provable Alignment Guarantees》关注 LLM 在问答系统中的选择性回答问题。

    当模型置信度不足时选择拒答，是降低幻觉和高风险误答的一条实用路线。相比单纯追求回答率，企业部署更需要知道模型何时不该回答。

## arXiv CausalGame 评测 LLM agent 因果推理能力
- source: arXiv
- date: 2026-07-05
- category: 论文,安全
- url: https://arxiv.org/abs/2607.04293
- summary: CausalGame 用互动游戏测试 LLM agent 的因果思维，发现主流 agent 在偏差和混杂因素下仍不可靠。
- detail: |
    arXiv 论文《Benchmarking Causal Thinking of LLM Agents in Games》提出 CausalGame，用互动场景测试 agent 区分相关性、因果性和隐藏偏差的能力。

    论文称多个 LLM agent 在选择偏差、测量误差和隐藏混杂因素下表现有限。对科学发现 agent 来说，这提示“能写研究计划”不等于真正具备稳健因果推理。
