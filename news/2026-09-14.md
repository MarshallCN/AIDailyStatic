## 论文：面向科学代码理解的检索增强生成——用小模型构建隐私友好的本地编码智能体
- source: arXiv（论文 cs.AI）
- date: 2026-09-14
- category: 论文,应用/产业
- url: https://arxiv.org/abs/2609.12190
- summary: 论文构建面向科学代码理解的 RAG 系统，把昂贵的离线解析与图构建/嵌入从轻量的在线问答阶段中严格分离，证明在质量上"模型家族与检索质量比参数量更关键"——9B 模型在 100 题基准上取得最高平均分 0.795，且优于嵌入 Claude Code 架构的同类模型。
- detail: |
    大型语言模型已成为现代编码助手的核心，但 Claude Code、Codex 这类系统依赖超大、云端托管的模型，带来显著的计算成本与数据隐私问题。这篇论文探讨的问题是：能否围绕小型开源模型构建一个"完全本地、有用"的编码智能体——方法不是缩小模型，而是把计算负担从"推理"端移到"索引"端。作者构建了一个用于科学代码理解的检索增强生成（RAG）系统，严格把昂贵的一次性离线阶段（解析、结构图构建、LLM 生成的实体解释、嵌入）与轻量的在线问答阶段分离。

    系统在覆盖 11 个类别的 100 题基准（围绕用 C++ 编写的 IPPL 科学代码库）上评估，答案由独立前沿模型作为裁判打分。跨七个问答模型，结论是"模型家族与检索质量比参数量更重要"：一个 9B 模型取得最高平均分 0.795，既超过自己管线内更大的模型，也超过同样模型嵌入到 Claude Code 检索架构中的表现。这项工作把"让代码理解前置于一个可复用、针对代码库特化的向量库"作为核心主张——对内部私有代码库而言，它证明了用忠诚的小模型即可交付有据可依、仓库专属的回答，是一条兼顾隐私与成本的产品化路径。

## 论文：K-Bench——在智能体化部署下为 LLM 遗忘建立基准
- source: arXiv（论文 cs.AI）
- date: 2026-09-14
- category: 论文,安全
- url: https://arxiv.org/abs/2609.12808
- summary: 论文指出 TOFU、MUSE 等遗忘基准只读模型最终答案，其"遗忘证书"在模型以智能体形态部署时并不成立；K-Bench 因而审查 ReAct 智能体暴露的全部六个通道（含思维链、工具调用与工具输出），只要是秘密出现在任一通道即算泄露。
- detail: |
    TOFU、MUSE 等"遗忘"（unlearning）基准通过阅读模型的最终答案来判断它是否已忘掉特定内容——一个拒绝回答的模型就已经被算作"忘掉了"。这篇论文指出，当模型被部署为智能体（agent）时，这种"模型级证书"并不成立。作者推出 K-Bench，一个专门评估智能体化部署下 LLM 遗忘的基准：它检查一个 ReAct 智能体暴露的全部六个通道，包括思维链（CoT）、工具调用、工具观察与最终的总结报告——只要秘密出现在任意一个通道里，该查询就计为一次泄露。

    实验清楚地暴露了"只看最终答案"的盲区：当秘密驻留在提示词或检索存储中时，TOFU 与 MUSE 报告"无泄露"，而实际部署的智能体在 22%–86% 的查询上仍然泄密（秘密原样留在工具观察通道里）；当秘密藏在权重中时，评估的二十种已发表方法没有一个能可靠地移除它，只有一种输入破坏（input-corruption）干预在评估者视角下实现了选择性遗忘，且排名靠前的方法会随基座模型变化而改变。对"遗忘"这一尚在早期、又号称能"卸载数据"的领域而言，这份工作是一个清醒的提醒：证书必须放在真实使用形态（智能体）里去检验，否则"被告知已遗忘"与"实际已遗忘"之间可能存在一个危险的缺口。

## 论文：Graph-of-Skills——面向海量智能体技能库的依赖感知结构化检索
- source: arXiv（论文 cs.AI）
- date: 2026-09-14
- category: 论文,生态
- url: https://arxiv.org/abs/2604.05333
- summary: 论文提出 Graph-of-Skills（GoS）：先在离线阶段为技能包构建可执行的技能图，再通过混合语义-词法种子、反向感知的 Personalized PageRank 与上下文预算约束的水合（hydration），检索出有界、依赖感知的技能包；在 SkillsBench 与 ALFWorld 的六个（模型×基准）组合上均取得最高平均奖励。
- detail: |
    随着 LLM 智能体在个人应用、网页浏览器等场景中广泛部署，其可复用技能库可能膨胀到数千条技能。这种规模带来两个问题：其一，把整个库加载进上下文会撑爆窗口，抬高 token 成本、延迟与幻觉；其二，纯语义检索会命中主题相关但缺少上下游前提的技能，形成"前提缺口"，导致检索出的技能包根本无法执行。Graph-of-Skills（GoS）为此设计了一个推理期（inference-time）的结构化检索层：离线阶段从技能包构建"可执行技能图"，在线阶段通过混合语义-词法种子检索、反向感知的 Personalized PageRank 与受上下文预算约束的水合，产出一个有界且依赖感知的技能包。

    实验横跨 SkillsBench 与 ALFWorld，搭配三类模型家族（Claude Sonnet 4.5、MiniMax M2.7、GPT-5.2 Codex），GoS 在全部六个（模型×基准）组合上取得最高平均奖励，同时 token 成本远低于加载完整库。在 SkillsBench 上用 GPT-5.2 Codex 时，它相较完整技能加载把平均奖励提升 7.0 个绝对点（相对提升 25.6%），同时砍掉 56.7% 的 token。消融实验进一步定位了机制来源：把反向遍历改成前向传播会损失 9.1 个奖励点，比完全移除技能图损失更大——增益来自逆依赖遍历本身，而非图扩散。对一个技能库动辄上千的智能体生态而言，这标志着一个从"全都塞进上下文"到"结构化地只带必要技能"的实用转向。
