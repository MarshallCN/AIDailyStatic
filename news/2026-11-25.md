## Anthropic 把 Messages API 从 Python 迁移到 Rust：CPU 降约 70%
- source: Anthropic
- date: 2026-11-25
- category: 基础设施
- url: https://www.anthropic.com/research/migrating-api-to-rust
- summary: Anthropic 详解其 Messages API 由 Python 迁至 Rust 的全程：单请求 CPU 降低约 70%、内存削减超 80%、中位首 token 延迟缩短约 20%，全程未停机。
- detail: |
    Messages API 是客户以及 Claude Code、Cowork 等自家应用访问 Claude 的主通道，从 2024 年初到 2026 年秋，流量增长了约 1800 倍，Python 在每次请求的校验、转换、分词与安全分类中都带来可观开销。Anthropic 决定迁到 Rust，Claude 约一周就写出了核心请求路径的首版。

    真正的难点是验证：生产 API 一直在变、Claude 对同一请求的输出不确定、又读不到客户请求。团队的解法是把生产 Messages API 本身变成校验器——让 Rust 版本在生产流量上以影子模式运行，自动找出分叉点并派 agent 修复差异。最终在不停服、不冻结功能开发的情况下完成切换。

    结果：单请求 CPU 使用减少约 70%，中位首 token 延迟改善约 20%（另有报道称内存占用降超 80%）。更值得借鉴的是工程组织方式的变化：工程师从“内圈”追差异，逐渐移向外圈，写规则和检查让 agent 在其间自主工作。用 AI 迁移一个每秒承载巨大流量的生产系统，这可能是目前最完整的一份实操记录。

## 专注“看不见数据”的隐私 AI 应用 Maple 获 530 万美元种子轮
- source: AI Weekly
- date: 2026-11-25
- category: 生态
- url: https://aiweekly.co/alerts/maple-raises-53m-to-run-ai-inside-trusted-execution-enclaves
- summary: 由前苹果工程师创办的隐私 AI 初创 Maple 获 530 万美元种子轮，把 DeepSeek、Kimi、GLM 等模型跑在可信执行环境里，公司自己也无法读取用户数据。
- detail: |
    Maple 由前苹果工程师 Mark Suman 与 Anthony Ronning 创办，融资由 Epic Ventures 领投，Draper Associates、Planetary VC、Epoch VC 参投。其应用在受信任执行环境（TEE）中运行 DeepSeek、Kimi、GLM、Gemma 与 GPT OSS 等模型，配合端到端加密，使公司自身都无法访问用户数据。

    公司称三个月内使用量增长了 60 倍。这一赛道与 OpenAI 同日发布的 Private Inference 遥相呼应——处理期隐私正在从“可选项”变成产品卖点：一端是 OpenAI 用机密计算服务企业客户，另一端是初创公司把开源模型装进硬件可信边界。

    隐私型 AI 应用能否规模化，仍取决于 TEE 的可用算力与模型生态的丰富度，但资本已经开始下注。
