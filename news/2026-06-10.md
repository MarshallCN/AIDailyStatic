## OpenAI 与 Oracle 扩大 Stargate 数据中心合作至 4.5GW
- source: OpenAI
- date: 2026-06-10
- category: 基础设施,应用/产业
- url: https://openai.com/index/stargate-advances-with-partnership-with-oracle/
- summary: OpenAI 宣布与 Oracle 合作新增 4.5GW Stargate 数据中心容量，推动美国 AI 基础设施建设。
- detail: |
    OpenAI 宣布与 Oracle 达成协议，将在美国开发额外 4.5GW 的 Stargate 数据中心容量。连同得州 Abilene 的 Stargate I，该合作将使在建 AI 数据中心容量超过 5GW，可运行超过 200 万颗芯片。

    OpenAI 称，这一进展推动其在四年内投资 5000 亿美元、建设 10GW AI 基础设施的承诺，并预计新增容量的建设、开发和运营会创造超过 10 万个岗位。

    这条新闻把模型竞争背后的物理约束摊开：领先模型公司的路线图越来越依赖电力、土地、供应链、网络和云合作伙伴。AI 产品速度最终会被基础设施交付速度约束。

## Google 发布开放实验模型 DiffusionGemma
- source: Google Blog
- date: 2026-06-10
- category: 开源,基础设施
- url: https://blog.google/innovation-and-ai/technology/developers-tools/diffusion-gemma-faster-text-generation/
- summary: Google 发布 Apache 2.0 许可的 DiffusionGemma，用文本扩散方式探索更快的本地生成。
- detail: |
    Google 发布 DiffusionGemma，这是一个基于 Gemma 4 的 26B MoE 开放实验模型，采用文本扩散方式一次生成文本块，而不是像自回归模型那样逐 token 解码。

    Google 称 DiffusionGemma 在专用 GPU 上可实现最高 4 倍文本生成速度，在单张 NVIDIA H100 上超过每秒 1000 tokens，并适合内联编辑、快速迭代和非线性文本结构生成等低延迟场景。

    该模型以 Apache 2.0 许可发布，定位仍是研究和开发实验而非最高质量生产模型。它的意义在于重新打开了文本生成架构路线：低延迟交互不一定只能靠更快的自回归解码。

## NVIDIA 为 DiffusionGemma 提供本地 RTX 和 DGX 优化
- source: NVIDIA Blog
- date: 2026-06-10
- category: 基础设施,开源,生态
- url: https://blogs.nvidia.com/blog/rtx-ai-garage-local-gemma-diffusion/
- summary: NVIDIA 宣布为 Google DiffusionGemma 提供本地硬件优化，覆盖 GeForce RTX、RTX PRO、DGX Spark 和 DGX Station。
- detail: |
    NVIDIA 发布博客称，已对 Google DeepMind 的 DiffusionGemma 做本地 AI 优化，使其可在 GeForce RTX、NVIDIA RTX PRO、DGX Spark 和 DGX Station 等平台上运行。

    NVIDIA 强调扩散式文本生成把解码瓶颈从内存带宽转向并行计算，更适合 Tensor Cores。博客给出的示例包括 H100 上 1000 tokens/sec、DGX Spark 上 150 tokens/sec 和 DGX Station 上最高 2000 tokens/sec。

    这类 day-zero 优化把开源模型发布和硬件平台销售更紧密地绑定起来。对开发者来说，模型是否开放只是第一步，能否在本地硬件和主流推理框架中稳定跑起来同样决定采用速度。

## 论文：Workflow-GYM 评测长程计算机使用 agent
- source: arXiv
- date: 2026-06-10
- category: 论文,基础设施
- url: https://arxiv.org/html/2606.11042
- summary: Workflow-GYM 构建长程专业软件任务基准，显示当前 GUI agents 在端到端工作流上仍明显受限。
- detail: |
    论文 “Workflow-GYM” 面向计算机使用 agent 的长程工作流评测，关注模型能否在专业软件环境中根据单条自然语言指令完成多步骤任务。

    作者评测了 GPT-5.4、Gemini、Kimi 和 Seed 等代表性模型及 agent 框架，并用隔离环境、截图观察和 GUI 操作来模拟真实工作流。结果显示，即使表现最好的模型平均通过率也只有约三成，明显低于短程 GUI 基准中的成绩。

    这项工作揭示了 agent 落地的关键短板：模型可以在短任务里显得灵活，但在专业软件、长依赖链和多阶段目标下，规划、状态跟踪和错误恢复仍然不足。

## 论文：Vortex 提供可编程稀疏注意力服务框架
- source: arXiv
- date: 2026-06-10
- category: 论文,基础设施
- url: https://arxiv.org/html/2606.06453v1
- summary: Vortex 让 AI agents 快速生成和优化稀疏注意力算法，并在长输入服务中提升吞吐与延迟表现。
- detail: |
    论文 “Efficient and Programmable Sparse Attention Serving for AI Agents” 提出 Vortex，面向长上下文模型服务的可编程稀疏注意力框架。

    论文展示 Claude Code 和 Codex 可被提示生成多种稀疏注意力算法，并通过 18 小时自主优化循环把吞吐提升到全注意力的数倍，同时尽量保持准确率。

    在服务评测中，Vortex 相比 SGLang 的全注意力在多种稀疏策略上获得更高吞吐和更低 P95 延迟。它把 AI agent 从应用层工具推进到系统优化参与者，让 agent 参与设计模型推理内核本身。
