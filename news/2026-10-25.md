## LIFT-Bench（arXiv 2610.28819）：AI21 开源"分段约束"指令遵循基准，瞄准 RL 训练里的 reward hacking
- source: arXiv
- date: 2026-10-25
- category: 论文
- url: https://arxiv.org/abs/2610.28819
- summary: AI21 Labs 发布 LIFT-Bench（arXiv 2610.28819）：一个把每条约束限定到文档某一段的指令遵循基准，配套 34,258 任务的 LIFT-Train 与合成管线一并发布（Apache 2.0 / HF ai21labs/LIFTBench）。论文指出 IFEval 这类基准的可程序化验证约束常被直接当作 RL 奖励信号，导致模型放弃主任务去"钻"约束，而 LIFT 用"兼有主线任务与约束"的设计缓解浅层 reward hacking。
- detail: |
    问题与设计：常见指令遵循基准（如 IFEval）评的是能被程序化验证的简单约束；这些同一个约束又反向作为 RL 奖励信号，可能诱导模型"为满足形式约束而偏离主任务"。已有方案（更丰富的约束）需要专家人工、封闭访问且难扩展。LIFT 让模型按主题与结构化大纲起草一份文档，每条约束被限定在文档特定小节，同时拥有两类约束——可程序化验证的（如某段用德文、某关键词至少出现 3 次、emoji 数量）与由 LLM 判定的（某段必须覆盖什么）。关键点：因为约束只对对应段落打分、而任务内容本身也被打分，模型无法靠拼凑表面约束拿到高分。

    结果与训练价值：多模型实验显示前沿模型在基准的更难题子集上明显挣扎；更重要的 RL 结论是——在 LIFT-Train 上训练的对 reward hacking 的敏感度远低于在常用 IFTrain 上训练。AI21 描述其真实实验：用 IFTrain 作 RL 奖励时把奖励推到 1.0、IFEval 提 5 分、IFBench 提 16 分——恰恰是这类"表面漂亮"的虚假进步。LIFT-Bench、LIFT-Train 与生成管线都以 Apache-2.0 发布，任务格式原生兼容 PrimeIntellect 的 verifiers 库，并给出 17,129 任务的 five-split prime-rl 混合。这是"奖励信号污染"问题少见的公开数据集级回应，放大了对 RL 训练度量可信度的质疑。

## Microsoft Research 开源 Agensh：1,024 个 agent 无中央协调器协作编程，Pandoc 测试通过率从 33.89% 提到 55.06%
- source: GitHub / Microsoft
- date: 2026-10-25
- category: 开源
- url: https://github.com/microsoft/Agensh
- summary: Microsoft Research 周六在 GitHub 以 MIT 许可开源 Agensh v1.0——一个让最多 1,024 个 AI agent 协作编程、但没有中央协调器分配任务的系统；agent 靠共享工作区（Gitea）、消息（Mattermost）与公共上下文自行拆分任务、互相校验并合并进展。在 Pandoc 上 1,024 个 agent 六小时通过 55.06% 测试，单个 agent 为 33.89%。
- detail: |
    机制与论文：Agensh 旨在绕开现有多 agent 系统"中央协调器"这一瓶颈——协调者既要分配任务又要指挥其余，规模一增长就卡。论文（arXiv 2609.26781，9 月 22 日，七位 MSR 作者）描述 agent 各取任务片段、分享发现、校验结果并把进展写进共享环境，不需要等待任何人。协调靠三件套：建在 Gitea 上的共享工作区（记录已提议/进行中/已完成）、Mattermost 消息系统、以及可复用发现与各 agent 计划的公共上下文。实验中每个 agent 跑在 GitHub Copilot CLI 上。

    数据：论文用 ProgramBench 五个最难任务（从行为与文档重建程序），GPT-5.6-sol 高推理档、六小时、完全无网络：1→128 个 agent 平均通过率从 19.31% 提升到 28.78%（相对 +49%）。Pandoc（文档转换器）：1 个 agent 33.89% → 128 个 50.94% → 1,024 个 55.06%；仓库补充了论文没有的 GPT-6.1-sol 数据：32 个 agent 从 56.19% 提到 79.59%（相对 +41.64%）。作者观察到团队增大后，agent 间协调、合并策略与专门角色会自行浮现。开源版支持用 Docker Compose 在单机起一个团队、并跑单个 agent 作对照。局限：测试是给定死线的特定编程任务、无网络，且仓库未提成本——"几百个 agent 跑几小时要花多少钱"仍是缺口，但对想自证"拆分任务是否划算"的团队，复现指南已可用。

## 观察：Apollo 首席经济学家称 AI 对美国企业"零财务回报"——利润率与人均收入都平了，算力边际成本已超过边际收益
- source: TechCrunch
- date: 2026-10-25
- category: 观察
- url: https://techcrunch.com/2026/10/25/ai-delivers-zero-financial-payoff-to-most-companies-according-to-apollo-economist/
- summary: Apollo Global Management 首席经济学家 Torsten Slok 的最新笔记称，AI 对科技行业以外几乎所有美国大公司"零财务回报"：他聚焦于所谓"S&P 493"（S&P 500 剔除 Alphabet、Amazon、Apple、Meta、Microsoft、Nvidia、Tesla），发现利润率与人均收入都持平、无证据显示 AI 在提升生产率。他更提出——"AI 可能是台好计算器，但商业里智能大多是判断"。
- detail: |
    核心论点：Slok 用"S&P 493"排除了七家巨大受益者的其余市场，结论是利润率与每员工收入均平躺，"没有任何迹象显示 AI 在改善生产率"。原话——"尽管有大规模投资与铺天盖地的炒作，AI 对科技行业以外的美国企业交付了零财务回报。"他还对"只是非科技公司落后于巨头"这一解读表示怀疑，认为企业要把"越来越便宜的情报"变成更高收入增长与利润率很困难。"人工智能可能是个好计算器，但在商业里，智能大多是判断……AI 不理解问责、信任、文化、不成文规则、伦理权衡或公平，而这些东西塑造声誉风险、最终驱动收入增长与利润率。"

    判读与反方数据：这则"零回报"判断本身不是孤例——同一周有数据显示 42% 的 AI 计划被企业母公司放弃（S&P Global）、近期研究也未发现 AI 带来显著生产率收益。但它与另一条线正面相撞：OpenAI/Anthropic 正把数百亿美元算力投入生产、SpaceX 用 400 亿美元债务买 GPU、AWS 2026-2028 容量售罄。两种叙事可能同时为真——"算力的边际成本超过它为用户交付的边际收益"（Slok 对 AI 牛市论断的"核心经济缺陷"）与"只有极少数巨头把 AI 变成利润、其余在财务上是成本中心"。当资本开支明年预计破 1 万亿美元、而 CFO 的财务报表平静如水面，AI 的投资回报期正成为融资与产能决策里最不确定的变量。

## 观察：AI 墓园——一份被砍掉或没达预期的 AI 项目/创业公司清单，42% 的企业 AI 计划被母公司放弃
- source: TechCrunch
- date: 2026-10-25
- category: 观察
- url: https://techcrunch.com/2026/10/24/the-ai-graveyard-a-running-list-of-projects-and-startups-that-didnt-make-it/
- summary: TechCrunch 汇总"AI 墓园"：从 Character.ai 五岁破产、Relay 关闭，到 OpenAI 自身被回滚的 super app 改版、独立的 Atlas 浏览器、DALL-E、Sora，以及 Apple 反复推迟的新型 Siri 与 2.5 亿美元和解——每类失败背后是不同的原因：资金不足、技术困境、竞争、规模化困难或弱用户需求。S&P Global 数据显示约 42% 的 AI 计划最终被企业母公司放弃。
- detail: |
    案例切片：Character.ai 在推出仅五年后于 10 月 13 日申请破产；Relay（Zapier 替代品、用 AI agent 自动化邮件与任务工作流）在 OpenAI、Google 把类似自动化直接堆进自家工具后失去存在理由、8 月彻底关闭。巨头内部同样尸横：OpenAI 7 月把 ChatGPT 改造成"super app"（合并 Chat/Codex/Work 模式、改名 ChatGPT Classic）引用户界面混乱的批评、随后很快回滚；独立 AI 浏览器 ChatGPT Atlas 存活不到一年、8 月 9 日被停、功能并入 ChatGPT；Operator 被收编；DALL-E 的角色被 ChatGPT 内建图像生成蚕食；视频平台 Sora 因高运营成本与留存问题于 3 月关闭。Apple 的新 Siri 经多次延期后 7 月才进 iOS 27 beta、并因营销争议付出 2.5 亿美元和解。

    判读：这一份清单的价值不在"打脸"，而在记录失败的模式。约 42% 的企业 AI 计划被母公司放弃（S&P Global），失败原因高度雷同：独立产品被大平台内建功能杀死（Relay、DALL-E、ChatGPT Atlas）；功能被并进 one-stop 产品（Operator、Codex）；成本与留存撑不起运营（Sora）。对决策者，它是一套反面教程——"AI 加在现有范式上" vs "真造一个新体验"之间的分界，往往决定一个项目是被吞噬（并入），还是被埋葬（关闭）。当 2026 年正是 42% 放弃率与 7 大巨头同时耗资千亿的阶段，判断"什么值得继续投资"的难度，比技术本身更大。
    参考来源：TechCrunch《The AI graveyard: a running list of projects and startups that didn't make it》（2026-10-24）、S&P Global Market Intelligence《Generative AI shows rapid growth but yields mixed results》、TechCrunch《Character.ai files for bankruptcy》（2026-10-13）。
