## Google I/O 发布 Gemini 3.5 Flash，把 Gemini 推向 agent 与编码工作流
- source: TechCrunch
- date: 2026-05-19
- category: 应用/产业,基础设施
- url: https://techcrunch.com/2026/05/19/with-gemini-3-5-flash-google-bets-its-next-ai-wave-on-agents-not-chatbots/
- summary: Google 在 I/O 2026 发布 Gemini 3.5 Flash，强调编码、agentic workflows 和 Search、Gemini app、企业工具中的默认分发。
- detail: |
    Google 在 I/O 2026 上把 Gemini 3.5 Flash 定位为面向 agent 和编码的新一代快模型。它进入 Gemini app、AI Mode in Search、AI Studio、Android Studio、Antigravity 和企业产品，说明 Google 不只是发布模型，而是在把 agent 能力接入既有分发网络。

    这对 OpenAI 和 Anthropic 构成不同压力：Google 的优势不只是模型分数，而是 Search、Android、Workspace、YouTube 和开发者工具的入口。Gemini 3.5 Flash 如果能在速度和成本上稳定运行，就可能把 agent 从独立产品变成 Google 生态默认能力。

## OpenAI 推进内容来源标记，强化 AI 生成内容透明度
- source: OpenAI
- date: 2026-05-19
- category: 安全,生态
- url: https://openai.com/index/advancing-content-provenance/
- summary: OpenAI 发布 content provenance 更新，继续推动 Content Credentials 等来源标记标准用于图像、视频和生成内容。
- detail: |
    OpenAI 表示将继续参与内容来源与透明度标准建设，并把 Content Credentials 等机制用于 DALL·E、ImageGen、Sora 等生成内容。随着多模态生成越来越逼真，内容是否可追溯会直接影响媒体、版权和公共信息环境。

    这类更新不会像新模型那样立刻改变能力上限，但会影响平台治理底座。生成式 AI 进入新闻、广告、教育和社交传播后，来源标记会成为防伪、审计和用户信任的基础设施。

- date: 2026-05-19
- category: 论文,应用/产业

- summary: Nature 发布 Google Co-Scientist 论文，展示多 agent 科研系统在假设生成、实验建议和药物重定向任务中的真实验证。

    这条新闻是 AI for science 的关键节点。过去很多科研 agent 只停留在文献综述或自动写作，Co-Scientist 更接近“提出可检验假设”的研究伙伴形态，也让论文评测和实验室验证开始连接。

## NVIDIA Vera CPU 开始交付给前沿 AI 客户
- source: IT Brief Asia
- date: 2026-05-19
- category: 基础设施
- url: https://itbrief.asia/story/nvidia-delivers-first-vera-cpus-to-anthropic-openai
- summary: 报道称 NVIDIA 已向 Anthropic、OpenAI、SpaceXAI 和 Oracle Cloud Infrastructure 交付首批 Vera CPU 系统。
- detail: |
    Vera CPU 面向 agentic AI、强化学习后训练、推理和实时分析等工作负载，目标是补齐 GPU 集群中 CPU 侧的吞吐和能效瓶颈。首批客户覆盖 Anthropic、OpenAI、SpaceXAI 和 OCI，说明前沿模型公司正在同时升级 GPU 与 CPU 基础设施。

    这提醒行业，AI 基础设施不是“买更多 GPU”这么简单。随着 agent 工作流包含大量代码执行、数据库查询、工具调用和调度逻辑，CPU、网络、内存和液冷系统都会成为 AI 工厂的一部分。
