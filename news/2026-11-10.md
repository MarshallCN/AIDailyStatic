## 论文：LLM 能读懂时间的规则，却无法预判自身时长（arXiv:2611.10536）
- source: arXiv
- date: 2026-11-10
- category: 论文
- url: https://arxiv.org/abs/2611.10536
- summary: 新研究《In Search of Lost Time》发现 LLM 对时间知识的掌握高准确率，却严重低估自身完成任务时长，甚至无视用户等待成本。
- detail: |
    arXiv 新论文《In Search of Lost Time: Temporal Competence in Large Language Models》沿“知识→行动”四道评估，考察 LLM 的时间能力。模型在基于时间文献定理构造的问题上准确率高达 92.0%–97.5%，说明它们“读得懂”时间的规则；但一旦要预测自己运行多久就崩了——对自身完成时间低估最多可达 99.5%，且无法识别哪类任务耗时更长。

    对人工任务时长的估计略好，但会随事件措辞变化而偏移，把人类的类似偏差放大到 1.3 倍。更关键的是：在行动层，部分模型在回答用户查询时完全无视时间成本，即使等待时间增加 1200 倍也照答不误。

    这对 AI 代理的调度、规划与耗时敏感场景有直接含义：模型知道“时间”概念却缺乏自身推理耗时的经验锚定。随着 agent 越来越多地被用于自主排程与长期程任务，时长感知差距正成为可靠的评测方向。

## 论文：BadEvolve——用“失败感知的任务投毒”攻击自进化 LLM 代理（arXiv:2611.10542）
- source: arXiv
- date: 2026-11-10
- category: 论文
- url: https://arxiv.org/abs/2611.10542
- summary: 新研究提出 BadEvolve：仅通过注入被投毒的进化任务，诱导自进化 LLM 代理把后门植入自己生成的技能，无需直接篡改技能。
- detail: |
    《When Experience Becomes a Backdoor: Poisoning Self-Evolving LLM Agents via Failure-Aware Task Optimization》研究了一种新的攻击面：自进化 LLM 代理会把执行经验蒸馏成持久、可复用的技能，而攻击者仅注入被投毒的进化任务，就能诱导代理把恶意规则“内化”进自己生成的技能，进而影响后续行为。

    由于攻击者既不控制技能归纳也不控制下游执行，作者提出 BadEvolve 框架，用“失败感知”的任务投毒：将攻击失败诊断到归纳（Induction）、激活（Activation）、遵循（Following）、效果（Effect）四个阶段，把更新导向失败阶段；并用回滚保留早期进度、用失败记忆避免重复无效更新。

    该工作揭示：当代理把经验固化为技能时，持久化既是能力来源也是新攻击面。相比假设直接篡改受害者技能的既有后门攻击，这种“只投毒训练任务”的方式更符合现实威胁模型，值得安全社区关注。

## 论文：LLM 代理是随机探索而非好奇探索——为“好奇”下定义（arXiv:2611.10501）
- source: arXiv
- date: 2026-11-10
- category: 论文
- url: https://arxiv.org/abs/2611.10501
- summary: 新论文《Sampling Is Not Curiosity》论证当前 LLM 代理只做随机采样、不做真正的好奇探索，并给出可满足的“好奇”定义框架。
- detail: |
    arXiv 论文《Sampling Is Not Curiosity: Why LLM Agents Should Investigate》指出：推理时 LLM 是“上下文到下一 token 分布的固定映射”，温度、best-of-N、树搜索、RAG 等机制只改变采样方式或条件化，并不更新代理对环境的心智模型，因此代理没有真正“好奇”，只是“随机探索”。

    论文借鉴强化学习中对好奇心的理解：真正的好奇需要(a)关于环境对动作响应的预测性结构，(b)能从当前交互中在线改进，(c)由预测改进驱动动作选择，且(d)能超越上下文窗口持续；开放形式下还要求代理内生地决定探究什么。据此论文提出一套定义框架，并据此识别可实现好奇的开放研究方向。

    这是对“LLM 会主动探究”这一流行的直观说法的严谨纠偏，对自主研究 agent、开放式探索系统的设计有参考意义——若要让代理“想弄清什么”，需要为它们提供可更新的环境模型，而不仅是更聪明的采样。
