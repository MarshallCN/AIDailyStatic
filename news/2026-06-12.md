## NVIDIA Blackwell 在 AgentPerf 基准中领先
- source: NVIDIA Blog
- date: 2026-06-12
- category: 基础设施
- url: https://blogs.nvidia.com/blog/nvidia-blackwell-agentperf-artificial-analysis/
- summary: NVIDIA 称 GB300 NVL72 在首个 agentic AI infrastructure benchmark 中，每兆瓦可运行 agent 数比 Hopper 高最多 20 倍。
- detail: |
    NVIDIA 报道 Artificial Analysis 的 AgentPerf 结果，称该基准基于真实 coding agent 轨迹，覆盖读取文件、编辑代码、执行命令和迭代调试等长序列工作负载。

    对 agent 来说，吞吐和能耗不再只是每秒 token 数。工具调用延迟、长上下文、命令执行间隔和多 agent 并发都会影响基础设施效率。
