## AgentSSL：把半监督学习当程序搜索，让 MLE agent 用上无标注数据
- source: arXiv
- date: 2026-11-14
- category: 论文
- url: https://arxiv.org/abs/2611.17323
- summary: NeurIPS 2026 论文提出 Agentic Semi-Supervised Learning，把 SSL 化为程序搜索问题，弱监督下在 12 项设定中 8 项超过最强人工基线。
- detail: |
    当前机器学习 agent（MLE agents）几乎只在全监督设定下被研究，忽略了现实里「标注稀缺、无标注数据充足」的常态。这篇被 NeurIPS 2026 接收的论文提出 Agentic Semi-Supervised Learning（AgentSSL），把半监督学习视为程序搜索问题，考察 agent 在有限监督下如何穿越这一空间。在弱反馈、等计算量条件下，agent 能合成并组合既有的 SSL 技术，在 12 项设定中的 8 项上以最高 +21.8% 超过最强人工基线。

    但研究同时暴露出关键瓶颈——程序选择：当用 agent 的反馈指标来选程序时，性能最高下降 47%。为系统研究这一点，作者引入 ProgramSelectBench，汇集 1.7 万份 agent 生成与人工的 SSL 程序，并评测无监督与主动选择方法；最后在真实生态检测任务上验证了从受控基准迁移的机遇与挑战。结论是「程序选择」而非「程序合成」最需要后续投入。

## CoReMem：让编码 agent 的记忆「内化成本」，用前瞻评估决定写什么
- source: arXiv
- date: 2026-11-14
- category: 论文
- url: https://arxiv.org/abs/2611.17316
- summary: 新论文提出 CoReMem 框架，让编码 agent 依据「下个任务的实测记忆价值」决定该写哪些记忆，在 ChainSWE 上把 27B agent 的解决率从 21.0% 提到 25.7%。
- detail: |
    编码 agent 在一套持续演进的代码仓库上连续完成任务，需要把编辑与记忆带向下一个未知任务；但「为未知的下一步选记忆」必须在未来价值与写入/读取成本之间权衡。CoReMem（Coding-Repository Memory）把这个成本内化进框架：通过「前瞻段评估」，对比带/不带某条轨迹段跑下一个任务的效果，把记忆压缩为以仓库位置与可执行检查为主题的锚点。

    作者并用「策略内记忆价值」估计 agent 何时该利用记忆省力，以「溯源门控的价值归因」把因使用锚点记忆产生的额外收益正确归到对应步骤。在 ChainSWE 上，CoReMem 把 27B actor 的解决率从 21.0% 提至 25.7%，同时步骤数减少 17%、含记忆模块的缓存感知 token 总数减少 11%。这是把「何时写记忆、写什么、何时读取」从工程直觉变成可度量的最优决策的一次尝试。
