- date: 2026-05-28
- category: 应用/产业,基础设施

- summary: TechCrunch 报道 Anthropic 完成 650 亿美元融资，投后估值 9650 亿美元，继续扩大 Claude 算力和产品合作。
- detail: |
    这轮融资把 Anthropic 推到接近 1 万亿美元估值，资金将用于安全和可解释性研究、扩展算力以及推进企业产品和合作伙伴关系。

    估值背后是 Claude Code、企业采用和前沿模型算力需求的组合。模型公司正在被资本市场视为新一代基础设施平台，而不是单纯软件公司。

## AWS 宣布 Claude Opus 4.8 可在 Amazon Bedrock 使用
- source: AWS
- date: 2026-05-28
- category: 基础设施,生态
- url: https://aws.amazon.com/blogs/machine-learning/claude-opus-4-8-is-now-available-on-aws/
- summary: Claude Opus 4.8 登陆 AWS，企业可通过 Bedrock 和 Claude Platform on AWS 使用新模型。
- detail: |
    Claude Opus 4.8 进入 AWS 说明前沿模型分发越来越依赖云平台。企业更愿意通过既有云安全、计费、区域和治理体系接入模型。

    这也让模型竞争变成云生态竞争：同一个模型是否进入 AWS、Google Cloud、Microsoft Foundry，会影响企业采用速度。
