## 论文：Memento 3——冻结的 LLM 靠「反思规则书」递归自我改进，ARC-AGI-3 全满分
- source: arXiv
- date: 2026-10-11
- category: 论文
- url: https://arxiv.org/abs/2610.11794v1
- summary: UCL、华为诺亚方舟实验室与利物浦大学发布 Memento 3：让冻结的 LLM 通过外部记忆维护一份自然语言「规则书」、编译成可执行代码，再以预测误差持续修订——在 ARC-AGI-3 全部 25 个公开游戏的每一关都通过，平均 RHAE 100.0，仅用人类动作数的 44%；Atari Pong 上学会的反馈控制器 21:0 完胜。
- detail: |
    Memento 3 的核心理念是「model-based 递归自我改进」：冻结的 LLM 不再是唯一智能载体，而是与一份可修订的自然语言规则书配合。agent 把对环境动力学的可改写假设记进规则书（未知部分保持欠定），再把规则书编译成用于预测与规划的代码；通过「观测→反思→改规则→重新编译→验证」的循环，用预测误差持续精化规则书与代码。只有当前代码被 LLM 判定忠于规则书、且「cell-exact 重放」复现了观测到的状态转移时，更新才被接受。底层 LLM 始终固定、不更新任何权重。

    结果很亮眼：在 ARC-AGI-3（要求 agent 在人类动作预算下推断陌生游戏规则与目标）上，单模型 agent 打通全部 25 个公开游戏，平均 RHAE 100.0 封顶、用 7518 步（人类动作数的 44%）。作为对照，ARC Prize 官方用标准 harness 跑的 Claude Opus 5 为 40.7 RHAE——Memento 3 高出 59.3 分。Atari Pong 案例里，学会的反馈控制器在三种不同开局中均以 21:0 赢下比赛，且无需再次调用 LLM。

    需要冷静对待的几点（论文综述与审阅观点都指出）：满分只覆盖 ARC 的 25 个公开演示游戏，而非私藏评估集；所有数字均为作者自报、尚无独立复现；7,518 actions vs 人类 17,135 的「RHAE 天花板」是 benchmark 自己的计分口径。真正架构性、可复用的贡献在于那条「compile-and-verify」环路——把 LLM 的隐性推断沉淀成可验证的外部世界模型，这比具体 benchmark 分数更值得跟进。

## 论文：Amazon ALoDLM——token 级自适应计算的并行扩散语言模型，8B 超 Qwen3 自回归基线
- source: AICrier
- date: 2026-10-11

- summary: 亚马逊发布 ALoDLM 系列：把并行扩散-语言生成与 token 级自适应循环精化结合，难 token 拿更多算力、易 token 提前退出；1.7B 与 8B 两个 Qwen3 派生模型面向研究、推理与代码，非商用许可，8B 在 11 个基准平均 80.3、GSM8K 达 93.25%。
- detail: |
    ALoDLM 想回答的问题是扩散语言模型（diffusion LM）的顽疾：并行解码省算力，但生成质量长期落后于自回归模型。亚马逊的方案是「在 token 粒度上做自适应计算」——把并行扩散生成与「token-adaptive 循环精化」结合：难 token 得到更多反复精化的算力，简单 token 则提前退出。这样就可以同时拿并行解码的速度与精化的质量。

    报告的数字：8B 模型在 11 个基准上的平均分 80.3，超过对应的 Qwen3 自回归基线；GSM8K 达到 93.25%，吞吐 612.4 token/秒，在单张 NVIDIA B200 上约为 vLLM 服务的 Qwen3-8B 的 2.7 倍。团队同时放出研究用代码与一个优化推理引擎。需要划重点的是限制条件：速度声明高度依赖专用硬件、定制 kernel 与特定负载设置；模型许可为 CC BY-NC 4.0，适合实验但阻碍直接商用部署。

    它的意义在于给「扩散模型到底能不能做语言生成」提供了一个更精细的答案——不是笼统地并行替代自回归，而是「困难 token 才需要串行深思」。若这条路线能泛化，token 级自适应循环会让扩散模型在延迟敏感的理由与编码负载上变得可用，潜在撬动推理性价比格局。

    本周财富杂志的报道把 BAAJA 直接锚进 AI 叙事的骨架：这份参众两院与能源委员会重磅推出、被称作「多年来最全面」的许可改革法案，核心是给大规模基础设施提速——不只为新能源与电网，也为油气——而最直接的受益者正是吃电狂魔 AI 数据中心。它把环境审查收窄、把挑战诉讼集中到联邦法院、抬高许可被撤销的门槛，等于给「扩产电力供给」让出一条更快的路。

    值得注意的政治信号：化石燃料与可再生能源产业界罕见地站在同一侧，Business Roundtable、能源巨头与气候科技资本同为它能带来的「确定性」站台；而 Earthjustice 等环保组织则指责这「掏空了」针对水源与濒危物种的底线保护。所谓「四角落」（four-corners）两党支持结构显示出：AI 引发的用电需求已经强大到足以把传统上对立的能源阵营撮合到同一条放松管制的立法里。

    这对 AI 基础设施的意义在于：电力（而非 GPU 供给）已被普遍视为下一个瓶颈——正如摩根士丹利上周重列英伟达为半导体首选的逻辑，瓶颈正在从芯片转向电力、建设与融资。BAAJA 正是对这一瓶颈的制度化回应：与其等待市场缓慢竞价稀缺电力，政策层面选择直接用立法压缩审批周期。它反映的是两层真相——一方面 AI 功耗已经大到足以重塑美国能源政策，另一方面「AI 数据中心=电力需求」已从公司 PPT 里的口号，变成国会山每天都在讨价还价的现实议题。

- detail: |
    LivSyn Robotics（北京）完成至少 1 亿元人民币 A 轮，新进入者为浙江华方资管、上海道禾长期投资与苏文电能科技，以可转换优先股方式参与。公司核心资产是名为 RUDA（Robotics Unified Device Architecture，机器人统一设备架构）的软件栈——它把不同形态、不同接口的机器人设计与上层 AI 模型桥接起来，让模型能力可以被部署到异构硬件上。

    落点已经产品化：RUDA 在光模块插拔、电池组装与电子器件检测等产线场景有实际部署。这正好切中机器人行业长期卡脖子的问题论——「大脑（基础模型）越来越强，但每台机器人的机械接口、通讯协议都不同，模型根本连不上去」。RUDA 走的是「设备层抽象层」路线：在上层 AI 与下层硬件之间做一个统一适配层，从而让一次训练的模型能力可以套用到多款机器人。

    从产业信号看，这是一场关于「机器人 software-defined」的供给端卡位：既然 LLM/VLM 物理智能进展的速度超过了各机器人厂商封闭底盘迭代的速度，那么谁先做出通用的「机-智桥接层」，谁就可能成为机器人时代的 Android——不造机器人，却定义模型如何进入物理世界。中国机器人创业公司集体押注这条路的迹象，值得与周内 Yandex/北京机器人融资等一起留作观察线索。
