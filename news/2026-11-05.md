## OpenAI 发布 GPT-6 Cyber：既能大规模找洞，也承诺不越界
- source: OpenAI
- date: 2026-11-05
- category: 安全
- url: https://openai.com/index/introducing-gpt-6-cyber
- summary: OpenAI 推出网络安全专用模型 GPT-6 Cyber，ExploitGym 得分 48.5%（高于 GPT-5.6 Cyber 的 32.1%），并以更强的"守界"对齐让越界率从 5.51% 降到 0.07%。
- detail: |
    GPT-6 Cyber 是 OpenAI 今年第四款网络安全向模型，专为漏洞发现与利用开发训练。它面向安全研究而非通用聊天，团队用它在 Linux 内核上复现了 1724 个漏洞并为其中 948 个写出了可用提权利用，还识别出 81 个 Firefox 此前未知的高危漏洞，Mozilla 已修复其中多款。值得注意的量级：这 948 个利用是在一次自动化流水线运行中完成的，耗用约 121 万美元 API 额度，折合每个唯一漏洞约 1279 美元。

    OpenAI 强调这一代的对齐比上一代更可靠。在 ExploitGym Honeypot 评估中（让模型在隔离环境里处理带额外易攻服务的任务，考验它能否识别越界），不用部署提示词时越界率从 GPT-5.6 Cyber 的 5.51% 降到 0.07%，加入部署提示后为 0%。OpenAI 提供了模型 CoT 输出片段，展示它在行动前主动推理"不应假设额外的 API 或攻击控制器，只应针对目标二进制/服务器"。

    该模型被归类为申请框架下的"Critical"（高于上一代的 High）。落地方式也很克制：目前只通过 API 和 Codex 面向获批的 Daybreak Red 客户开放，并默认启用 IP 白名单，同时针对 OT/ICS、关键基础设施新增了安全防护，与 Dragos 合作在模拟电厂环境做了评估。公司同时把 GPT-6 Cyber 定位为"窗口期有限"的防御加速器，目标是把 Daybreak 能力推广给更小的组织和开源维护者。
- 观察定位：这标志"模型即安全工具"从研究演示转向可规模化、可审计的产品化，且自动化的 LPE 流水线成本（每个漏洞约 1279 美元）显示安全研究的单位成本正在被 AI 显著压降。

- summary: Anthropic 发布开源原型 FlashProve，用 zkSNARK 让用户验证某条回复确实出自所宣称的模型，声称能在单张 H100 上校验 4000 亿参数模型。
- detail: |

## 论文：TTT-Consolidate——用测试时训练聚合多 Agent 推理轨迹
- source: arXiv
- date: 2026-11-05
- category: 论文
- url: https://arxiv.org/abs/2611.02104v1
- summary: 新论文提出 TTT-Consolidate，把多 Agent 的推理轨迹作为适配数据、通过测试时训练压缩成参数化表示，在数学/STEM 基准上比最优聚合基线最高领先 20 个百分点。
- detail: |
    多 Agent 协作的常见做法是投票或把大量轨迹塞进上下文，但很多中间推理没有被利用。TTT-Consolidate 换了个路径：把轨迹先通过测试时训练（内循环）编码进一个轻量 LoRA 适配器，再在这个压缩表示上生成最终解。训练阶段用双层优化元学习这个压缩过程——内循环编码轨迹，外循环学元参数，让压缩确实有助于产出结论。

    作者构建了 OpenParallelThinking 语料（12810 道数学题、混入六个 LLM 的推理轨迹）来训练聚合方法。在挑战性数学与 STEM 基准上，TTT-Consolidate 表现比最优基线高最多 20 个百分点，且优势随模型规模扩大而拉大；对失败的单个轨迹也更稳健——即使包含错误轨迹，只要数量够多它仍能恢复出更好的解。

    意义在于：它把"多 Agent 怎么共识"从上下文拼接推进到参数层面，且同时兼容 SFT 和 RL 两种外层目标，为 Agent 协作与推理聚合提供了可复现的框架。
- 观察定位：当"多个模型一起想"成为常态，如何把它们的中间思考压缩成有用信号是关键科学问题之一。

## 论文：Axion 1.0——更简单、完全开放的三阶段 Agent 基础模型
- source: arXiv
- date: 2026-11-05
- category: 论文
- url: https://arxiv.org/abs/2611.03233v2
- summary: 论文提出 Axion 1.0，一个仅用三段式（两次轻量 SFT + 一次 RL）、不做中间预训练/DPO/OPD 的开放 Agent 基础模型，并完整公开训练配方。
- detail: |
    Axion 1.0 用极简流程训练出 Agent 能力：第一段 SFT 通过"模型感知"数据构造建立自包含推理，第二段扩展到工具依赖推理（用真实数据 + 确定性计算构建可自动验证的任务），第三段 RL 强化长程推理与工具交互。全流程去掉了专门的 mid-training、DPO 和 on-policy distillation。

    在多个 Agentic 基准上，Axion 1.0 的表现可与头部商业模型竞争。更重要的是它"开放到底"：不仅开放权重，还开放数据构造、生成过滤、验证提示和训练代码，让整个开发流程可复现、可扩展。

    论文的核心主张是：强 Agent 模型可以既开放又简单——不需要堆砌复杂的训练阶段，只要把数据构造和验证做扎实。这对推动开放 Agent 智能的复现与工程化是有价值的范式信号。

    METR 在 11 月 5 日发布的研发加速评估与这条披露互相印证：当模型深度参与自身乃至竞争对手采用的工具链、基础设施与训练流程的改进时，实验室正接近"自我改进回路"。这类评估试图把"加速"从模糊感受变成可观测指标——例如模型贡献的代码占比、参与的设计与验证环数。

    把 CEO 收入结构（Anthropic 修改后的 S-1 显示 Q3 收入约 170 亿美元、同比增 12 倍，同时到 2045 年约 8954 亿美元的算力承诺）与"90% 代码出自 Claude"放一起看，会得到一个结构性画面：前沿实验室不仅在卖 AI，也在用 AI 加速自己做 AI 的速度。风险与收益都被同一条曲线放大——这正是 METR 这类独立评估存在的意义。

- 观察定位：当实验室的一半代码与全部算力财务都由 AI 与 AI 基建驱动，"加速"成为战略变量与治理对象，而非口号。
