## Google I/O 后，搜索型 agent 成为周末讨论焦点
- source: TechCrunch
- date: 2026-05-23
- category: 应用/产业,生态
- url: https://techcrunch.com/2026/05/19/how-to-use-googles-new-ai-agents-to-go-beyond-your-standard-searches/#2026-05-23
- summary: Google I/O 发布的搜索 agent 功能继续被讨论，用户开始评估 AI Mode 是否会替代传统搜索结果页。
- detail: |
    Google 将 Gemini agent 接入 Search 后，搜索不再只是返回链接，而是尝试规划、比较、总结和执行任务。这让搜索产品从信息入口变成任务入口。

    但这种变化也会改变网站流量、广告、来源透明度和用户控制权。搜索 agent 是否能赢得信任，会决定 Google 能否把 I/O 发布转化为日常使用习惯。

## Gmail 对话式查询展示工作流 AI 的入口价值
- source: TechCrunch
- date: 2026-05-23
- category: 应用/产业
- url: https://techcrunch.com/2026/05/19/you-can-now-talk-to-your-gmail-inbox-as-seen-at-google-io-2026/#2026-05-23
- summary: Google I/O 的 Gmail AI 演示显示，邮箱、日历和文档正在成为工作流 agent 的天然入口。
- detail: |
    Gmail 中的对话式查询让用户用自然语言检索邮件、整理事项和理解上下文。相比独立聊天机器人，邮箱拥有天然的个人和工作信息上下文。

    这也带来更高的隐私和权限要求。工作流 agent 越靠近邮件、日历、文件和联系人，越需要清晰的数据边界和用户可控性。

## Anthropic RSP 提醒搜索与办公 agent 需要能力门槛
- source: Anthropic
- date: 2026-05-23
- category: 安全,基础设施
- url: https://www.anthropic.com/news/announcing-our-updated-responsible-scaling-policy#2026-05-23
- summary: 随着搜索和办公 agent 能力增强，Anthropic RSP 的能力分级思路继续适合作为发布前风险参照。
- detail: |
    搜索和办公 agent 看似低风险，但一旦拥有跨应用访问、自动执行和长期记忆，就会产生数据泄漏、越权操作和错误行动风险。

    RSP 代表的治理方法说明，模型公司不能只根据用户体验来发布 agent 功能，还要根据工具访问范围和潜在损害设置安全门槛。

## 周末论文线索：agent 评测从问答转向任务完成和权限控制
- source: arXiv
- date: 2026-05-23
- category: 论文,安全
- url: https://arxiv.org/list/cs.AI/recent#agent-permission-evals-2026-05-23
- summary: 本周搜索、Gmail 和编码 agent 的集中发布，使 agent 评测继续从静态问答转向任务完成、权限边界和失败恢复。
- detail: |
    当 agent 能跨工具执行任务，评测必须关注它是否理解权限、能否恢复失败、是否会越权读取或写入数据，以及能否向用户解释行动依据。

    这类评测会成为产品发布和企业采购的共同语言，因为它更接近真实组织部署中的风险。
