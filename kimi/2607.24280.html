Q1: 这篇论文试图解决什么问题？

该论文旨在解决**将专有模型（proprietary teacher）的推理能力高效迁移至开源学生模型（open-source student）时面临的异构蒸馏瓶颈与分布差距问题**，具体体现在以下三个层面： --- ### 1. 传统蒸馏机制在专有模型场景下失效 基于 Logit 匹配的知识蒸馏（如 KL 散度对齐）依赖于可访问的教师 token 分布。然而，专有模型仅暴露黑盒 API，其内部 logits 不可见，且与开源模型使用异构分词器（heterogeneous tokenizers），导致数学上的 token 级对齐无定义。 ### 2. 自由形式自然语言轨迹模仿引发风格漂移与幻觉 作为常见退而求其次的方案，直接让学生模型模仿专有模型生成的自然语言推理轨迹（Chain-of-Thought / agentic trajectories），会迫使学生拟合教师特有的语言外壳——包括冗长的表达习惯、权威语气及格式伪影。这种**表层风格迁移**不仅无法传递底层的认知策略（如任务分解、多跳证据聚合），反而加剧分布差距，导致严重的**风格漂移（style drift）**与**幻觉（hallucination）**，显著降低 agentic 任务性能。 ### 3. 结果导向的强化学习信号过于稀疏 Agentic search 涉及多轮检索与生成交错的复杂轨迹，而基于最终答案正确性的二元奖励（$R \in \{0,1\}$）仅能提供稀疏的轨迹级监督，难以对中间推理、检索查询与诊断步骤进行细粒度的信用分配（credit assignment）。 --- ### 核心解决思路 为弥合上述差距，论文提出 **Multi-Agent Protocol Distillation (MAPD)**：利用一个**结构化的、风格归一化的 JSON 协议**作为中间表示，将专有模型的核心认知策略（任务类型、推理计划、抽取式证据、答案验证）与其特有的语言外壳解耦。该协议由离线多智能体系统（MAS）合成，在训练阶段作为**特权信息（privileged information）**注入学生策略的特权分支，通过同模型的自蒸馏（OPSD）提供密集的 token 级监督，与稀疏的 GRPO 强化学习目标联合优化。这样既能规避 logits 不可见与分词器异构的障碍，又能抑制风格漂移，实现从专有到开源的安全高效迁移。

Q2: 有哪些相关研究？

该论文在第 5 节系统梳理了三个密切相关研究方向的代表性工作，并阐明了其与 MAPD 的区别与联系： --- ### 1. 大语言模型推理与智能体搜索（LLM Reasoning and Agentic Search） 近期研究范式已从静态单轮推理转向动态多轮智能体任务，其中智能体搜索（agentic search）通过将多步逻辑推理与环境增强检索相交错，处理知识密集型挑战。代表性框架包括： - **WebRL**（Qi et al., 2025b）：采用自进化强化学习并结合过程级奖励； - **Search-R1**（Jin et al., 2025）：利用经典强化学习算法优化多轮检索； - **RAGEN**（Wang et al., 2025）：通过基于轨迹的奖励优化检索增强推理链。 然而，上述策略主要由稀疏的、仅依赖最终结果（如终端答案正确性）的奖励信号驱动，难以对中间规划、检索与诊断步骤进行细粒度的信用分配。为突破该优化瓶颈，MAPD 提出了一种联合训练范式，将结果驱动的强化学习信号与密集的蒸馏信号相结合。 --- ### 2. 面向专有模型的知识蒸馏（Knowledge Distillation from Proprietary Models） 将专有大型语言模型的能力迁移至更小规模的开源模型已成为主流范式： - **经典知识蒸馏**（Hinton et al., 2015）依赖匹配输出概率分布，但该机制在仅暴露黑盒 API 且存在异构分词器的专有模型场景下 fundamentally 不可行； - **文本级模仿方法**转而蒸馏专有教师生成的自然语言推理轨迹或思维链（Chain-of-Thought）（Hsieh et al., 2023; Mukherjee et al., 2023; Xu et al., 2025）。 近期研究（Gudibande et al., 2023）指出，直接模仿无约束的教师轨迹会迫使学生过拟合到教师特有的冗长语言模式与权威语气，引发能力不匹配，进而导致严重的风格漂移与幻觉。为应对此问题，MAPD 将教师的语义策略提取到风格归一化的结构化 JSON 协议中，从而将核心推理逻辑与专有语言外壳解耦，实现安全的在线自蒸馏。 --- ### 3. 面向复杂推理的多智能体系统（Multi-Agent System for Complex Reasoning） 基于大语言模型的多智能体系统（MAS）已在复杂推理与开放式问题解决中展现出显著潜力（Wu et al., 2023; Hong et al., 2024; Lei et al., 2024）。在检索增强场景中，多智能体协作通过并行子查询编排与迭代辩论，能够显著提升多步问题的召回率（Du et al., 2023; Talebirad & Nadiri, 2023; Wang et al., 2026a）。 然而，在推理时部署此类协作智能体集群会带来过高的计算开销、严重延迟与巨大 API 成本，使其难以适用于实时应用。与上述方法不同，MAPD 仅在离线训练阶段将多智能体系统用作知识合成器，通过结构化协议将协作问题解决策略蒸馏到单一学生模型中，从而在测试时实现零开销推理。

Q3: 论文如何解决这个问题？

该论文提出 **Multi-Agent Protocol Distillation (MAPD)**，通过一个风格归一化的结构化协议作为中间表示，将离线知识提取与在线策略优化解耦。具体解决方案可分为以下三个核心组件： --- ### 1. 结构化 JSON 协议（Structured JSON Protocol） 为规避自由形式自然语言轨迹导致的风格漂移与幻觉，MAPD 设计了一种紧凑的、风格归一化的 JSON 协议作为蒸馏的基本单元。该协议将专有模型的核心认知策略与其特有的语言外壳解耦，形式化地定义为一个结构化对象 $z$，其通过描述性模板 $f(\cdot)$ 转化为特权信息 $p = f(z)$。 协议 $z$ 涵盖五个关键维度： - **Task Type**：由专有专家判定，将查询归类为 `single_hop`、`multi_hop`、`comparison` 或 `others`，以指导顶层认知策略； - **Reasoning Plan**：有序的子目标数组，将复杂任务严格分解为可执行的检索与推理步骤； - **Grounding Facts**：从检索环境提取的精选证据集合，强制要求忠实推理并抑制参数化幻觉； - **Partial Findings**（可选）：当多轮搜索未能收敛时，记录中间发现的中性摘要； - **Answer Verification**：最终提取的答案及其布尔支撑标志 `answer_grounded`，确保结论被检索事实严格支持。 通过该协议，学生模型无需暴露于教师特有的冗长表达与格式伪影，仅需内化其语义层面的推理与证据组织策略。 --- ### 2. 多智能体系统生成流程（Multi-Agent System Generation Pipeline） 为从专有教师可靠地提取上述结构化知识，论文构建了一个离线的三阶段多智能体系统（MAS），并实施严格的质量控制： **Stage A：多智能体协作搜索（Multi-Agent Collaborative Search）** - **Orchestrator**：将问题 $x$ 分解为带显式依赖注解的子任务，并按拓扑层级并行分发给独立的 **Searcher** 智能体； - **Searcher**：每个智能体最多发出 $K$ 次查询至本地维基百科语料，将检索到的段落压缩为简洁发现； - **Repair**：在初始探索后，通过精确匹配（EM）检查候选答案。若失败，Repair 智能体以 ground-truth 答案为诊断引导（严格不将其泄露至探索日志或检索查询），回溯推理链，区分“表达问题”或“搜索问题”，并触发针对性的再分解与补充搜索。 Stage A 的输出包含原始问题、候选答案、二元成功标签，以及详尽的探索日志。 **Stage B：协议生成（Protocol Generation）** - **Protocolizer** 智能体根据成功标签将原始日志转化为两种 JSON 变体之一： - **Succeeded Protocol**：包含完整验证答案； - **Evidence Protocol**：用于失败轨迹，省略确定性答案，代之以 `partial_findings` 的中性总结。 - 严格施加两条完整性约束： - **No Hindsight**：`reasoning_plan` 必须逐步制定，禁止提及最终结果或后续搜索结果，防止数据泄露； - **Extractive Grounding**：`grounding_facts` 必须是检索段落中的严格逐字子串。 **Stage C：质量门控（Quality Gate）** 生成的协议须通过四项自动化检查： 1. **Schema Validation**：JSON 结构合法； 2. **EM Consistency**（针对成功协议）：提取答案与 ground truth 严格匹配； 3. **Grounding Verification**：所有事实均为抽取性子串匹配； 4. **Leak Detection**：推理步骤中未注入先知知识。 未通过任一检查的协议将被丢弃，对应训练回退至自展开基线。该流程在 3,000 个实例上达到 99.33% 的高质量协议产出率。 --- ### 3. 联合训练目标（Joint Training Objective） 在训练阶段，结构化协议作为特权信息（Privileged Information, PI）仅注入学生策略的特权分支，通过在线策略自蒸馏（OPSD）与基于结果的强化学习（GRPO）联合优化： **在线策略自蒸馏（OPSD）** 在同一模型参数下构建两个条件分支： - **学生分支**：条件上下文为 $s_t = (x, y_{<t})$； - **教师分支（特权分支）**：条件上下文为 $s_t^+ = (x, p, y_{<t})$，其中 $p$ 为 MAS 生成的协议。 在反向传播中仅对学生路径施加梯度，最小化每步的反向 KL 散度： $$ \mathcal{L}_{\text{OPSD}}^{(t)} = D_{\text{KL}}\left( \pi_{\theta_k}(\cdot \mid s_t) \,\|\, \pi_{\theta_k}(\cdot \mid s_t^+) \right) $$ 该同源（homologous）形式天然规避了专有-开源模型间的词表不匹配问题，同时利用协议提供的密集信号优化中间决策。 **基于结果的强化学习（GRPO）** 采用 Group Relative Policy Optimization 提供稀疏的轨迹级监督。对于给定提示 $x$，采样 $G$ 条轨迹 $\{y^{(i)}\}_{i=1}^G$，基于终端奖励计算优势 $\hat{A}^{(i)}$，并优化裁剪后的代理目标： $$ J_t^{(i)} = \min\left( \rho_t^{(i)} \hat{A}^{(i)}, \,\text{clip}\left( \rho_t^{(i)}, 1-\epsilon, 1+\epsilon \right) \hat{A}^{(i)} \right) $$ $$ \mathcal{L}_{\text{GRPO}} = -\frac{1}{G} \sum_{i=1}^{G} \frac{1}{|y^{(i)}|} \sum_{t=1}^{|y^{(i)}|} \left( J_t^{(i)} - \beta D_{\text{KL}}\left( \pi_\theta \,\|\, \pi_{\text{ref}} \right) \right) $$ **总体目标** 将上述两项结合为统一的联合损失函数： $$ \mathcal{L}(\theta) = \lambda_{\text{OPSD}} \cdot \mathcal{L}_{\text{OPSD}}(\theta) + \mathcal{L}_{\text{GRPO}}(\theta) $$ 其中超参数 $\lambda_{\text{OPSD}}$ 控制蒸馏信号的相对强度。$\mathcal{L}_{\text{OPSD}}$ 提供密集的 token 级监督以实现高效的逐步信用分配，而 $\mathcal{L}_{\text{GRPO}}$ 通过裁剪策略梯度优化最终环境奖励，二者协同避免学生策略陷入浅层检索捷径或风格退化。 --- 综上，MAPD 通过“离线 MAS 协议合成 + 在线同源自蒸馏与强化学习联合训练”的架构，在不暴露专有 logits、不承担推理时 MAS 开销的前提下，实现了从专有教师到开源学生的安全、密集且可迁移的知识迁移。

Q4: 论文做了哪些实验？

论文在第 4 节及附录中开展了系统的实验验证，涵盖以下七个方面： --- ### 1. 实验设置 **数据集与评测基准** 训练仅使用 NQ 与 HotpotQA 的训练集拆分；评测覆盖 7 个知识密集型 QA 基准，分为： - **单跳推理**：NQ、TriviaQA、PopQA - **多跳推理**：HotpotQA、2WikiMultihopQA、MuSiQue、Bamboogle 其中 5 个评测集完全未在训练中出现，作为分布外测试；对于 NQ 与 HotpotQA，则严格保证训练/测试问题无重叠。评测指标为基于精确匹配（EM）的 **成功率（success rate, %）**。 **基线方法** - **Vanilla**：预训练基线模型零样本评测 - **OPSD**（Zhao et al., 2026）：纯在线策略自蒸馏，以学生自身成功轨迹作为特权信息 - **GRPO**（Shao et al., 2024）：纯结果导向强化学习，无密集蒸馏信号 - **GRPO+OPSD**：简单混合 RL 与自蒸馏，使用成功轨迹作为特权信息 - **SDAR**（Lu et al., 2026）：结合 RL 与 token 级门控蒸馏的先进混合基线 - **MAPD**：本文提出的完整框架 **实现细节** 学生模型选用 **Qwen3-1.7B** 与 **Qwen3-4B**（均从各自预训练基座初始化）。训练配置包括：每提示采样 $n=8$ 条轨迹，批次大小 128，最大提示长度 4096，最大响应长度 512；学习率 $1\times 10^{-6}$，线性预热 10%，共训练 200 步，使用 8 张 GPU。Agentic 环境允许最多 4 轮交互，检索后端为 wiki-18，每查询返回 top-3 段落。 **MAS 管道配置** 默认以 **Claude-Opus-4.6** 作为协议合成骨干，并额外探索 **GPT-5.5** 与 **Gemini-3.1-Pro**。MAS 参数约束：Orchestrator 每查询最多分解为 4 个子问题，最多 2 轮；每个 Searcher 最多发出 3 次检索查询；Repair 智能体最多 2 轮诊断。所有协议均离线预合成并缓存，与学生的 RL 训练循环完全解耦。 --- ### 2. 主实验结果（7 个 QA 基准评测） 如论文 Table 1 所示，MAPD 在全部 7 个基准上持续优于所有基线： - **Qwen3-1.7B**：平均成功率 **39.4%** - **Qwen3-4B**：平均成功率 **44.4%** 相比最强基线 SDAR，MAPD 分别取得 **4.8%** 与 **3.3%** 的相对平均提升。关键发现包括： - **多跳任务增益显著高于单跳**：在 Qwen3-1.7B 上，多跳平均相对增益达 **7.9%**，远超单跳的 2.3%；Qwen3-4B 上分别为 5.1% vs. 1.8%。这与 MAS 管道系统化分解复杂查询、聚合跨步证据的设计目标一致。 - Q5: 有什么可以进一步探索的点？

基于论文所揭示的范式潜力与实验边界，以下从**协议表示、系统架构、训练机制、理论分析与应用拓展**四个维度梳理可进一步探索的方向： --- ### 1. 协议表示的动态化与跨任务泛化 当前 MAPD 采用固定的五维 JSON 协议，其设计深度耦合于知识密集型 QA 任务。未来可探索： - **自适应协议模式（Adaptive Protocol Schema）**：不再使用人工预定义字段，而是让模型根据任务复杂度动态生成协议结构。例如，在代码生成场景中协议可能包含 `API Dependency Graph` 与 `Execution Trace`，在视觉推理中则需融入 `Visual Grounding Anchors`。这要求建立一种元协议（meta-protocol）机制，使结构化中间表示能够随任务域自动扩展。 - **跨模态协议蒸馏**：将 MAPD 从纯文本检索扩展至多模态智能体（如视觉-语言导航、图表推理）。此时特权信息可能同时包含文本推理计划与视觉注意力掩码，需要设计异构模态的对齐目标，例如在多模态分支上施加模态内 KL 散度约束： $$ \mathcal{L}_{\text{OPSD}}^{\text{multi}} = D_{\text{KL}}\left( \pi_{\theta}^{\text{text}}(\cdot \mid s_t) \,\|\, \pi_{\theta}^{\text{multi}}(\cdot \mid s_t^+) \right) + \lambda_{\text{vis}} \cdot \mathcal{L}_{\text{vision}} $$ - **协议压缩与分层语义编码**：当前协议以自然语言描述的 JSON 呈现，token 开销不可忽视。探索将其编码为紧凑的连续向量（如使用轻量编码器），在更低维度传递特权信号，可能进一步降低训练不稳定性并提升泛化。 --- ### 2. 多智能体系统的高效化与自动化 论文中的 MAS 依赖人工设计的角色分工（Orchestrator / Searcher / Repair / Protocolizer）与高成本专有模型调用： - **开源模型驱动的自举协议合成**：验证是否可用经过微调的开源小模型（如 Qwen3-1.7B 自身或其放大版本）替代 Claude-Opus-4.6 等专有模型执行 MAS 角色。若可行，将大幅降低一次性合成成本，并可能通过迭代自举（iterative bootstrapping）实现“学生→教师”的闭环自我改进。 - **自动化 Agent 发现与拓扑优化**：当前 MAS 的协作拓扑（串行分解→并行检索→修复）是静态的。引入自动机器学习（AutoML）或图神经网络搜索最优智能体拓扑，可能发现比人工设计更高效的证据收集与错误恢复策略。 - **可学习的质量门控（Learned Quality Gate）**：现有门控依赖硬规则（Schema Validation、EM Consistency、Leak Detection 等）。训练一个轻量级验证器（verifier）或过程奖励模型（PRM）来端到端评估协议质量，可能减少 0.67% 的协议丢弃率，并捕获更微妙的语义错误（如事实性矛盾但满足子串匹配的情况）。 --- ### 3. 训练目标的精细化与理论理解 MAPD 采用固定权重 $\lambda_{\text{OPSD}}$ 的加和式联合目标，论文仅通过网格搜索确定最优值： - **自适应蒸馏强度调度**：$\lambda_{\text{OPSD}}$ 可设计为随训练动态衰减的函数 $\lambda(t)$，例如早期依赖密集协议信号建立正确行为先验，后期逐步让位于 GRPO 的环境反馈，实现“训练轮次上的课程退火”。形式化地： $$ \lambda(t) = \lambda_0 \cdot \exp(-\gamma t) + \lambda_{\min} $$ 这可能在避免 $\lambda=0.10$ 时“检索而不推理”崩溃的同时，获得比固定 0.05 更优的收敛。 - **特权信息渐进式遮蔽（Privileged Information Fading）**：当前协议在训练全程可见。探索在训练后期逐步遮蔽协议中的关键字段（如先隐去 `answer`，再隐去 `reasoning_plan`），迫使学生模型逐步内化能力而非持续依赖外部提示，最终实现在测试时零协议依赖的完全自主推理。 - **不同散度度量的对比研究**：论文采用反向 KL 散度 $D_{\text{KL}}( \text{student} \| \text{teacher} )$。系统对比正向 KL、Jensen-Shannon 散度、Wasserstein 距离或对比学习（contrastive）目标在协议蒸馏中的表现，可能揭示哪种度量更适合保持学生模型原生分布与吸收教师策略之间的平衡。 --- ### 4. 理论机制与更广泛的评测 - **风格漂移的形式化度量与因果分析**：论文定性指出风格漂移问题，但未给出形式化度量。未来可建立基于统计距离（如分布间的 Maximum Mean Discrepancy）或语言学特征（句法树深度、语气词频率、推理动词分布）的量化指标，并因果分析结构化协议具体抑制了哪些表层特征的吸收。 - **测试时协议增强（Test-Time Protocol Augmentation）**：当前协议仅用于训练。探索在推理阶段让学生模型自生成草稿协议（draft protocol）并基于此执行检索，可视为一种测试时计算扩展（test-time scaling）策略。例如，模型先输出隐式的 `reasoning_plan`，再据此发出检索查询，最后基于检索结果修正计划，形成“推理-检索-再推理”的迭代自增强。 - **对抗鲁棒性与噪声检索场景**：论文假设检索后端提供相对干净的维基百科段落。在更具对抗性的环境（如网页搜索返回广告/ SEO 垃圾信息、或科学文献检索中的矛盾证据）中，检验 MAPD 的 `grounding_facts` 与 `answer_verification` 机制是否仍能有效抑制幻觉，并研究是否需要引入冲突消解（conflict resolution）字段到协议中。 - **多教师集成与知识互补**：论文分别测试了三种专有模型，但未探索融合多教师协议的可能性。通过集成 Claude、GPT 与 Gemini 各自生成的协议（例如投票式 `grounding_facts` 或加权 `reasoning_plan`），可能构造出超越任何单一教师的“超教师”信号，并进一步验证结构化表示的模型无关性极限。

Q6: 总结一下论文的主要内容

该论文针对**将专有大型语言模型（proprietary LLM）的推理能力迁移至开源学生模型（open-source student）以优化智能体搜索（agentic search）**这一核心问题，提出了 **Multi-Agent Protocol Distillation (MAPD)** 框架。以下是论文的主要内容总结： --- ### 1. 研究背景与核心挑战 智能体搜索要求模型在多轮交互中交错进行推理与检索，以完成知识密集型任务。现有优化方法面临三重瓶颈： - **稀疏监督**：基于结果正确性的强化学习（RL）仅提供轨迹级二元奖励，难以对中间检索与推理步骤进行细粒度信用分配； - **异构蒸馏障碍**：传统基于 logit 匹配的蒸馏依赖可访问的教师 token 分布，但专有模型的隐藏 logits 不可见，且与开源模型存在异构分词器，导致数学对齐无定义； - **风格漂移与幻觉**：直接模仿专有模型生成的自由形式自然语言轨迹，会迫使学生过拟合到教师特有的冗长表达与格式伪影，无法传递底层认知策略，反而加剧分布差距与幻觉。 --- ### 2. 方法：Multi-Agent Protocol Distillation (MAPD) MAPD 通过引入**结构化、风格归一化的中间表示**，将离线知识提取与在线策略优化解耦，核心包含三个组件： #### 2.1 结构化 JSON 协议（Structured JSON Protocol） 协议 $z$ 被设计为一种紧凑的 JSON 格式，将核心推理策略与专有语言外壳解耦，包含五个维度： - **Task Type**：任务类型（如单跳/多跳/对比）； - **Reasoning Plan**：可执行的子目标分解序列； - **Grounding Facts**：从检索环境抽取的严格逐字证据； - **Partial Findings**（可选）：失败轨迹的中间发现摘要； - **Answer Verification**：最终答案及其事实支撑标志。 通过描述性模板 $f(\cdot)$ 转化为特权信息 $p = f(z)$，学生模型仅暴露于语义层面的策略，而非教师特有的表层语言模式。 #### 2.2 离线多智能体系统生成管道（MAS Pipeline） 利用专有模型驱动的多智能体系统离线合成高质量协议，严格隔离 ground-truth 以防数据泄露，包含三个阶段： - **Stage A：多智能体协作搜索** - **Orchestrator** 将查询分解为带依赖注解的子任务，分发给并行 **Searcher** 智能体执行检索； - **Repair** 智能体在精确匹配失败后，以 ground-truth 为诊断引导（不泄露至日志），区分表达错误或搜索错误并触发修复。 - **Stage B：协议生成** - **Protocolizer** 将原始探索日志转化为结构化的 Succeeded Protocol 或 Evidence Protocol； - 强制施加 **No Hindsight**（推理计划禁止提及最终结果）与 **Extractive Grounding**（证据必须为检索文本的逐字子串）约束。 - **Stage C：质量门控** - 通过 Schema Validation、EM Consistency、Grounding Verification、Leak Detection 四项自动化检查过滤低质量协议，产出率达 99.33%。 #### 2.3 联合训练目标（Joint Training Objective） 将密集的在线策略自蒸馏（OPSD）与稀疏的结果导向强化学习（GRPO）相结合： - **OPSD 蒸馏信号**：在同一学生模型参数下构建两个分支——学生分支基于上下文 $s_t = (x, y_{<t})$，特权分支基于 $s_t^+ = (x, p, y_{<t})$。通过最小化反向 KL 散度提供逐 token 的密集监督： $$ \mathcal{L}_{\text{OPSD}}^{(t)} = D_{\text{KL}}\left( \pi_{\theta_k}(\cdot \mid s_t) \,\|\, \pi_{\theta_k}(\cdot \mid s_t^+) \right) $$ - **GRPO 强化学习信号**：基于终端奖励的裁剪策略梯度，驱动模型优化最终答案正确性： $$ \mathcal{L}_{\text{GRPO}} = -\frac{1}{G} \sum_{i=1}^{G} \frac{1}{|y^{(i)}|} \sum_{t=1}^{|y^{(i)}|} \left( J_t^{(i)} - \beta D_{\text{KL}}\left( \pi_\theta \,\|\, \pi_{\text{ref}} \right) \right) $$ - **总体目标**： $$ \mathcal{L}(\theta) = \lambda_{\text{OPSD}} \cdot \mathcal{L}_{\text{OPSD}}(\theta) + \mathcal{L}_{\text{GRPO}}(\theta) $$ 该设计无需访问专有 logits，天然规避词表不匹配问题，且协议仅在训练时作为特权信息，推理阶段零开销。 --- ### 3. 实验验证 #### 3.1 主实验结果 在 7 个知识密集型 QA 基准（单跳：NQ, TriviaQA, PopQA；多跳：HotpotQA, 2WikiMultihopQA, MuSiQue, Bamboogle）上评测： - **Qwen3-1.7B** 平均成功率达 **39.4%**； - **Qwen3-4B** 平均成功率达 **44.4%**。 相比最强基线 SDAR，分别取得 **4.8%** 与 **3.3%** 的相对提升，且多跳任务的增益显著高于单跳任务。 #### 3.2 消融实验 - **结构化协议至关重要**：直接使用原始自然语言轨迹蒸馏反而劣于无专有模型的基线，验证了风格漂移与分布差距的严重性；引入结构化协议后性能显著提升； - **MAS 与协议互补**：MAS 单独使用（无结构化协议）因轨迹噪声而性能下降；单智能体生成协议虽优于原始轨迹，但不及完整 MAS 管道生成的协议； - **OPSD 权重敏感性**：$\lambda_{\text{OPSD}} = 0.05$ 为最佳平衡点；过小导致信号过早消失，过大则引发"检索而不推理"的行为退化。 #### 3.3 跨教师迁移性 在未修改架构与超参的前提下，分别以 Claude-Opus-4.6、GPT-5.5、Gemini-3.1-Pro 作为教师来源，三者性能方差极小（在 2 个百分点以内），证明结构化协议成功剥离了教师特有的风格伪影，实现了跨专有模型的无缝迁移。 #### 3.4 成本分析 离线合成 25,600 条实例的协议总成本约 **$1,454**（约 $0.057/实例），且协议预合成缓存，推理阶段无额外开销。 --- ### 4. 核心贡献 - 提出了 MAPD，一种**联合在线自蒸馏与结果导向强化学习**的框架，无需专有 logits 即可桥接专有教师与开源学生之间的分布差距； - 设计了**风格归一化的结构化 JSON 协议**作为中间表示，将核心认知策略与语言外壳解耦，有效抑制风格漂移与幻觉； - 构建了**鲁棒的多智能体系统管道**，通过自动化协作搜索、修复与质量门控，可靠地合成高质量协议； - 在多个基准上验证了 MAPD 的**一致优越性**与**跨教师泛化能力**，为异构模型对齐提供了一条安全、高效且可扩展的路径。
