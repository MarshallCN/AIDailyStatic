Q1: 这篇论文试图解决什么问题？

该论文旨在解决**大型语言模型（LLM）Agent 的可复用技能优化问题**，重点克服现有方法在评估和精炼技能时面临的效率瓶颈。具体而言，论文试图解决以下核心挑战： 1. **候选技能效用评估成本高昂** 现有方法通常依赖基于执行的“生成—评估—精炼”循环，必须在任务或验证实例上实际执行候选技能后，才能观测其真实效用。这导致大量优化预算被耗费在评估低质量或缺乏前景的技能上，造成严重的资源浪费。 2. **技能精炼过程本身代价昂贵** 现有方法往往反复调用 LLM 分析执行轨迹、诊断失败原因，并生成或聚合技能修改。尽管基于实际执行证据构建技能能够产生有潜力的候选，但在整个优化过程中持续重新分析轨迹和重写技能会带来巨大的额外开销。 3. **有限预算下的选择性分配与证据复用** 在计算资源和任务经验受限的情况下，关键挑战被形式化为一个**预算化的顺序优化问题**：如何在动态演化的候选技能空间中，有选择地分配有限的评估预算，同时高效复用执行反馈证据以持续精炼技能，而非穷举式地评估和反复重写候选。 为此，论文提出将技能优化建模为在动态变化候选空间上的上下文赌博机（contextual bandit）问题——每个候选技能被视为由其语义嵌入描述的臂（arm），其效用只能通过代价高昂的目标 Agent 执行来揭示。基于此设定，论文设计了 **COBRA-Skills** 框架，通过上下文赌博机引导的优先级排序来高效分配评估资源，并结合基于证据的种群演化（再生、 rollout 突变、交叉）实现技能的持续优化。

Q2: 有哪些相关研究？

该论文的相关研究主要围绕两大主题展开：**Agent 技能与技能优化**，以及**自适应优化中的赌博机方法**。 ### 1. Agent 技能与技能优化 **技能表示与获取** 现有研究将技能视为从先前经验中蒸馏出的可复用程序性知识，以编码任务特定指南、推理策略或工具使用流程（Xu & Yan, 2026; Ling et al., 2026; Zhou et al., 2026b）。早期工作关注如何外部化这些知识，包括经验蒸馏、工作流诱导和技能生成（Wang et al., 2023; Zhao et al., 2024; Liang et al., 2026; Yang et al., 2026b; Chen et al., 2026）。 **基于执行反馈的技能进化** 近期研究 increasingly 聚焦于从执行轨迹和反馈中自动构建与优化技能。例如，Trace2Skill（Ni et al., 2026）和 SkillRL（Xia et al., 2026）通过分析实际 Agent 轨迹来提炼技能；CoEvoSkills（Zhang et al., 2026）和 EvoSkill（Alzubi et al., 2026）则采用迭代式进化精炼，通过生成、验证和修订来提升技能质量。然而，这些方法通常依赖**基于执行的生成—评估—精炼循环**（Yang et al., 2026a; Liu et al., 2026c; Zhang et al., 2026），需要反复调用 LLM 分析轨迹、诊断失败并聚合修改，导致优化成本高昂。 **技能检索、组合与持续进化** 随着技能库规模增长，另一支研究线关注推理时的技能检索、排序、组合与注入（Zheng et al., 2026b; Cho et al., 2026; Su et al., 2026; Liu et al., 2026a; Meng et al., 2026）。近期工作还探索了效用感知的技能检索与持续技能记忆进化（Tu et al., 2026a;b）。此外，SkillsBench（Li et al., 2026）、SWESkills-Bench（Han et al., 2026）等基准研究揭示了技能有效性在不同任务与模型间存在显著差异（Liu et al., 2026b; Shaposhnikov et al., 2026）。 ### 2. 自适应优化中的赌博机方法 **上下文赌博机基础** 多臂与上下文赌博机为不确定性下的顺序决策提供了 exploitation 与 exploration 平衡的理论框架（Abbasi-Yadkori et al., 2011; Chowdhury & Gopalan, 2017; Lattimore & Szepesvári, 2020; Bouneffouf et al., 2020）。Li et al. (2010) 与 Chu et al. (2011) 提出的线性上下文赌博机为基于特征表示的臂选择奠定了算法基础。 **神经上下文赌博机** 为支持非线性奖励预测与表示学习，后续研究发展了神经上下文赌博机方法（Zhou et al., 2020; Xu et al., 2020; Dai et al., 2022），将深度表征与不确定性估计相结合。 **在提示优化中的应用** 赌博机机制已被应用于提示（prompt）优化领域，以实现自适应候选评估与提示空间探索。例如，基于神经赌博机与 Transformer 的指令优化（Lin et al., 2023）、自动提示优化中的“梯度下降”与束搜索（Pryzant et al., 2023）、以及 PromptAgent（Wang et al., 2024a）和 FedPOB（Lu et al., 2025）等框架，均利用 UCB 风格的探索来高效分配评估预算。 ### 3. 与现有工作的区分 与上述研究不同，COBRA-Skills 的核心定位在于：将技能优化形式化为**动态演化候选空间上的预算化顺序优化问题**。该框架并非静态地检索或合成技能，而是通过**上下文赌博机引导的优先级排序**来同时管理评估分配与种群保留，并结合**基于证据的进化算子**持续更新候选空间，从而在有限预算下实现更高效的技能搜索。

Q3: 论文如何解决这个问题？

论文通过提出 **COBRA-Skills** 框架解决上述问题。该框架将技能优化形式化为**在动态演化候选空间上的预算化顺序优化问题**，并通过两个核心机制的紧密耦合实现高效优化：一是**上下文赌博机引导的优先级排序**，用于选择性分配昂贵评估预算；二是**基于证据的技能进化**，用于从执行反馈中持续生成和精炼候选。具体解决方案如下。 --- ### 1. 问题形式化：预算化顺序优化 论文将技能优化定义为一个在有限轮次 $T$ 内的顺序决策过程。令 $\mathcal{D}_{\text{opt}}$ 为从目标任务分布中采样的少量优化样本，$\mathcal{T}_0$ 为无技能初始轨迹。在每一轮 $t$，算法从当前候选种群 $\mathcal{P}_t$ 中选择一个技能 $s$，由目标 Agent $\mathcal{A}$ 在 $\mathcal{D}_{\text{opt}}$ 上执行，获得奖励 $r_t$（如下游任务性能）和轨迹 $\mathcal{T}_t$。目标是在优化结束时识别出泛化能力最强的技能： $$ s^\star = \arg\max_{s \in \mathcal{S}_T} \mathbb{E}_{(x,y)\sim \mathcal{D}} \left[ \text{Metric}\left( \mathcal{A}(x; s), y \right) \right] $$ 其中，候选技能的效用无法先验得知，只能通过目标 Agent 的**执行反馈**来揭示，这构成了评估瓶颈。 --- ### 2. 上下文赌博机引导的技能搜索 为解决“评估哪个候选”的选择性分配问题，论文将每个候选技能视为上下文赌博机中的一个臂（arm），其特征为该技能的语义嵌入 $z_s = \phi(s)$。通过结合**利用**（exploitation）与**探索**（exploration）来指导每一轮的评估决策。 #### 2.1 神经奖励预测（利用） COBRA-Skills 维护一个轻量级的两层 MLP $f_\theta$，基于已累积的评估历史 $\mathcal{H}_{t-1} = \{(s_i, z_i, r_i)\}$ 来预测候选技能的期望奖励。在每轮评估后，模型通过最小化带 $\ell_2$ 正则化的均方误差进行重训练： $$ \mathcal{L}(\theta) = \frac{1}{|\mathcal{H}_t|} \sum_{(s_i,z_i,r_i)\in \mathcal{H}_t} \left( f_\theta(z_i) - r_i \right)^2 + \beta \|\theta\|_2^2 $$ #### 2.2 LinearUCB 探索奖励 为避免仅利用当前高预测分数的技能而忽略尚未充分探索的候选，论文引入 LinearUCB 风格的置信区间奖励。对于候选嵌入 $z_s$，其探索奖励为： $$ b_t(z_s) = \nu \sqrt{z_s^\top A_{t-1}^{-1} z_s} $$ 其中 $A_{t-1} = \lambda I + \sum_{i=1}^{t-1} z_{s_i} z_{s_i}^\top$ 为正则化设计矩阵，$\nu$ 控制探索强度。嵌入空间中评估数据稀疏的区域会保留更高的探索奖励。 #### 2.3 优先级分数与选择 综合预测奖励与探索奖励，形成候选技能的优先级分数： $$ U_t(s) = f_{\theta_{t-1}}(z_s) + \nu \sqrt{z_s^\top A_{t-1}^{-1} z_s} $$ 每一轮，算法选择优先级最高的技能进行评估；在种群更新时，同样使用该分数识别并**剪除低优先级的技能**。 --- ### 3. 基于证据的技能进化 为解决“如何高效复用执行证据以生成更好候选”的问题，COBRA-Skills 以**预定调度**（基于对数间隔）触发种群更新，而非每轮都进行昂贵的 LLM 重写。每次更新时，淘汰 $m$ 个低优先级技能，并通过三种**基于证据的进化算子**填补空位： - **再生（Regeneration）**：直接从无技能初始轨迹 $\mathcal{T}_0$ 中独立采样轨迹，生成全新的候选技能。该算子不依赖现有父代技能，可引入全新搜索方向，维持种群多样性，避免早熟收敛。 - **Rollout 突变（Rollout Mutation）**：对**当前轮被选中并评估的技能** $s_t$ 进行局部精炼。算法从其成功与失败的执行轨迹 $\mathcal{T}_t$ 中采样具体证据，指导教学模型 $M_{\text{teach}}$ 进行保守的、有针对性的修改，保留有效策略的同时修正失败模式。 - **交叉（Crossover）**：利用跨历史的累积证据进行性能导向的重组。算法将历史已评估技能划分为高性能组与低性能组，随机选取一个高性能技能作为**骨干**，另一个高性能技能提供**正向证据**，低性能技能提供**负向证据**，以此修订骨干技能。该算子实现了策略的重组与优化，而非简单的文本拼接。 新产生的技能**不继承**任何历史奖励估计，必须重新进入赌博机评估循环，从而保证评估的公平性。 --- ### 4. 闭环优化流程 整体流程形成如下闭环： 1. **优先级排序**：基于当前历史 $\mathcal{H}_{t-1}$ 计算种群 $\mathcal{P}_t$ 中所有候选的 $U_t(s)$。 2. **目标评估**：选择 $\arg\max_{s \in \mathcal{P}_t} U_t(s)$ 交由目标 Agent 执行，获得真实奖励 $r_t$ 与轨迹 $\mathcal{T}_t$。 3. **模型更新**：将新观测加入历史 $\mathcal{H}_t$，更新设计矩阵 $A_t \leftarrow A_{t-1} + z_{s_t} z_{s_t}^\top$，并重训练神经预测器 $f_{\theta_t}$。 4. **种群进化**：当满足预定调度条件时，依据更新后的优先级分数淘汰低价值技能，并通过再生、Rollout 突变与交叉算子生成新技能，构成 $\mathcal{P}_{t+1}$。 --- ### 5. 关键设计带来的效率提升 - **选择性评估**：通过上下文赌博机将预算优先分配给高潜力或高不确定性的候选，避免在劣质技能上浪费目标 Agent 的调用。 - **调度式进化**：技能生成与精炼仅在预定时刻触发，且直接基于累积的执行证据，避免了每轮重复进行 LLM 轨迹分析和全文重写的巨大开销。 - **双重利用优先级分数**：同一分数机制既指导**评估选择**，又指导**种群保留/剪除**，确保种群始终包含有前景的候选。 通过上述设计，COBRA-Skills 在仅使用 **50 个优化样本**和 **30 轮评估**的情况下，将总优化成本相较于 SkillOpt 降低了 **55%–58%**，同时取得了更强的平均性能。

Q4: 论文做了哪些实验？

论文围绕 **6 个异构 Agent 基准**与 **3 个目标模型**开展了系统的实验评估，涵盖性能对比、成本效率、跨环境泛化、优化动态与多项消融分析。具体实验内容如下： --- ### 1. 主性能对比实验 在 **SearchQA、SpreadsheetBench、DocVQA、LiveMath、SocialMaze、ALFWorld** 六个基准上，对比了以下方法： - **Baseline**：无外部技能 - **LLM Skill**：仅基于无技能轨迹做证据接地生成，不做后续优化 - **Trace2Skill**（Ni et al., 2026）：从执行轨迹中蒸馏可复用技能 - **SkillOpt**（Yang et al., 2026a）：基于目标 Agent 执行反馈的迭代技能优化 - **COBRA-Skills**：论文提出的完整方法 实验在 **Qwen3.6-35B-A3B、GPT-5.4-Nano、Gemma-4-26B-A4B-it** 三个能力层次不同的目标模型上独立运行。结果表明，COBRA-Skills 在全部三个模型上均取得最高的平均测试性能，相比无技能基线分别提升 **13.1、26.9、22.5** 个百分点（Table 1 & Fig. 2）。 --- ### 2. 优化效率与成本分析 量化了各方法的优化开销，包括： - 教师模型（Teaching Model）与目标模型（Target Model）的 Token 消耗 - 总优化成本（按固定 API 单价折算为 USD） - **Cost/ΔScore**（每提升 1 个百分点所需的成本） COBRA-Skills 将总优化成本相较 SkillOpt 降低 **55%–58%**，Cost/ΔScore 降低 **60%–69%**；同时仅使用 **50 个优化样本**，而对比方法通常使用更大规模的优化池（Table 2）。 --- ### 3. 跨 Agent Harness 泛化实验 为验证方法不依赖于特定的执行接口，以 **Qwen3.6-35B-A3B** 为目标模型，将优化得到的技能在 **Claude Code** 和 **Codex** 两种外部 Agent Harness 下进行测试。COBRA-Skills 在两种外部 Harness 上均取得最高平均性能（Table 3），表明其学到的技能具有良好的接口泛化性。 --- ### 4. 优化动态分析 从两个互补视角追踪优化过程： - **检查点性能（Checkpoint Performance）**：在优化过程中途截断，比较 COBRA-Skills 与 SkillOpt 当前输出的技能在测试集上的性能随累计成本的变化曲线。结果显示 COBRA-Skills 在多数基准上以相对较低的额外成本即可达到强劲性能（Fig. 3、Fig. 8、Fig. 9，分别对应三个目标模型）。 - **每轮优化轨迹（Per-round Dynamics）**：记录 COBRA-Skills 在 30 轮迭代中每轮所选技能的即时优化奖励 $r_t$。三条目标模型的曲线均呈现早期快速上升、后续持续精修的趋势（Fig. 4）。 --- ### 5. 消融实验（Ablation Studies） #### 5.1 Bandit 引导与技能进化的有效性 设计了三组变体以解耦核心组件： - **w/o Bandit**：保留进化算子，但候选评估与剪除改为随机选择 - **w/o Evolution**：对固定大小的技能池（30 个候选）应用 Bandit 优先级排序，不触发进化更新 - **Best-of-30**：生成 30 个固定候选并全部评估，返回最佳者 结果显示，移除任一组件均会导致平均性能下降（分别下降 2.2 与 2.4 个百分点），且 Best-of-30 仍低于完整方法 2.5 个百分点（Table 4），证明 Bandit 引导与种群进化具有**互补贡献**，且增益并非来自单纯增加候选数量。 #### 5.2 对教学模型的依赖性（自教学设置） 将外部教师模型 GPT-5.5 替换为**目标模型自身**（Self-teaching），检验 COBRA-Skills 是否必须依赖更强的外部模型。结果显示： - 平均性能仅从 73.5% 微降至 72.5% - 优化成本降低约一半 - 在两种教师设置下均优于 SkillOpt（Fig. 5 & Table 7） #### 5.3 跨模型技能迁移 将在某一目标模型上优化得到的技能，直接在另外两个目标模型上评估（保持 GPT-5.5 作为固定教师）。在 36 组跨模型迁移中，**34 组**均优于对应目标模型的无技能基线，且常常带来大幅提升（Fig. 6）。这表明优化后的技能捕获的是**任务级通用策略**，而非与特定目标模型过拟合的提示。 #### 5.4 探索–利用权衡敏感性 对 LinearUCB 探索系数 $\nu$ 进行敏感性分析（在 Qwen3.6-35B-A3B 上平均六个基准）。性能随 $\nu$ 增大先升后降，在 $\nu = 0.1$ 处达到峰值（Fig. 7），验证了适度探索对平衡利用与发掘不确定候选的重要性。 --- ### 6. 补充实验结果（附录） - Q5: 有什么可以进一步探索的点？

基于论文所提出的框架与实验观察，以下几个方向值得进一步探索： --- ### 1. 动态臂空间下的理论保证 论文将技能优化建模为候选空间动态演化的上下文赌博机问题，但尚未建立严格的**遗憾（regret）分析**。未来可探索： - 在允许添加/删除臂（技能）且臂特征由神经网络嵌入给出的条件下，分析在线学习算法的累积遗憾界； - 理论刻画证据接地进化算子（再生、突变、交叉）对收敛速度与最优技能识别概率的影响。 --- ### 2. 层次化与组合式技能优化 当前框架输出**单一文本技能**，而在复杂任务中，Agent 往往需要**多个技能的动态组合**或**层次化技能库**。可进一步研究： - 将技能优化从“单技能选择”扩展为“技能集合的子集选择”或“技能图（Graph-of-Skills）”上的组合优化； - 引入技能间的依赖关系建模，优化技能组合在下游任务中的协同效应。 --- ### 3. 在线与终身学习场景 论文假设优化集 $\mathcal{D}_{\text{opt}}$ 在事前固定，且优化 horizon $T$ 有限。更具挑战性的设定包括： - **非平稳任务分布**：当任务分布随时间漂移时，如何设计带有遗忘机制的技能种群更新策略； - **开放式技能积累**：在持续到来的新任务流中，维护一个不断增长的技能记忆库，并解决旧技能与新技能之间的冲突与冗余。 --- ### 4. 教学模型与目标模型的能力差距 实验初步显示自教学（目标模型同时作为教学模型）仍可获得强劲性能，但教学模型与目标模型之间的**能力差距（capability gap）**对优化效率的影响尚未量化： - 系统研究不同能力层级教师模型（如强 GPT-5.5 对弱本地模型）如何影响技能质量、收敛速度及跨模型迁移性能； - 设计自适应教学模型选择策略，根据当前技能种群的演化阶段动态切换教师模型。 --- ### 5. 评估效率与多目标权衡 论文主要优化单一性能指标，而实际部署通常面临**成本、延迟、准确率**等多重约束。未来工作可考虑： - 构建**多目标帕累托前沿**，联合优化技能性能与目标 Agent 推理成本（如输出 token 长度、API 调用次数）； - 引入**早停（early stopping）与迁移评估**机制，利用廉价代理模型（cheap proxy）预测高成本目标模型的执行结果，进一步减少真实评估次数。 --- ### 6. 多模态与具身智能体中的技能演化 实验涵盖文本问答、电子表格、视觉文档与文本化具身环境，但未涉及更复杂的多模态交互。可扩展至： - **视觉-语言-行动（VLA）技能**：在需要视觉感知与物理动作连续交互的具身场景中，优化包含视觉参考与运动原语的结构化技能； - **多智能体协作技能**：在多个 Agent 共享或竞争技能库的场景中，研究分布式或博弈论视角下的技能演化。 --- ### 7. 可解释性、安全性与对抗鲁棒性 当前技能通过 LLM 自动生成，其内部决策逻辑缺乏透明性。值得探索： - **可解释的技能编辑**：使进化算子不仅修改技能文本，还输出结构化的“编辑理由”（如基于哪条轨迹证据、针对何种失败模式）； - **对抗鲁棒性**：检验优化后的技能是否对提示注入、分布外输入或教师模型误导具有鲁棒性； - **反事实评估**：量化技能中具体哪一部分指导对下游性能贡献最大，避免过度拟合优化集 $\mathcal{D}_{\text{opt}}$ 的虚假相关性。 --- ### 8. 与提示优化（Prompt Optimization）的深度集成 技能可视为系统提示（system prompt）的一种特定形式。未来可将 COBRA-Skills 与现有的提示优化方法（如基于梯度的提示搜索或神经赌博机提示优化）结合： - 在**统一空间**中联合优化高层技能（任务策略）与低层提示格式（输出结构、 few-shot 示例）； - 利用技能嵌入空间中的 bandit 机制指导提示变体的搜索，实现跨层次的协同优化。

Q6: 总结一下论文的主要内容

该论文提出了 **COBRA-Skills**，一个面向大型语言模型（LLM）Agent 的高效技能优化框架。以下是论文的主要内容总结。 --- ### 1. 研究背景与核心问题 LLM Agent 可通过可复用的**技能（skills）**来编码任务特定的程序性知识（如推理策略、工具使用规范），从而提升下游任务表现。然而，现有技能优化方法普遍依赖**基于执行的生成—评估—精炼循环**，存在两个关键瓶颈： - **评估成本高昂**：候选技能必须在任务实例上实际执行，才能观测其真实效用，导致大量预算耗费在低质量候选上； - **精炼成本高昂**：反复调用 LLM 分析执行轨迹、诊断失败并重写技能，带来巨大 token 开销。 论文将技能优化重新形式化为一个**在动态演化候选空间上的预算化顺序优化问题**：在有限的评估轮次 $T$ 内，从不断变化的技能候选集合中，选择性分配昂贵的目标 Agent 评估预算，以识别泛化最优的技能。 --- ### 2. 方法：COBRA-Skills COBRA-Skills 通过两个核心机制的紧耦合解决上述问题：**上下文赌博机（contextual bandit）引导的优先级排序**与**基于证据的技能进化**。 #### 2.1 上下文赌博机引导的搜索 每个候选技能 $s$ 被表示为语义嵌入 $z_s = \phi(s)$，视为一个上下文臂。其优先级分数由两部分构成： - **利用项**：轻量级 MLP $f_{\theta_{t-1}}(z_s)$ 基于累积历史 $\mathcal{H}_{t-1}$ 预测期望奖励； - **探索项**：LinearUCB 风格的置信区间奖励，用于衡量嵌入空间中的不确定性： $$ b_t(z_s) = \nu \sqrt{z_s^\top A_{t-1}^{-1} z_s} $$ 其中 $A_{t-1} = \lambda I + \sum_{i=1}^{t-1} z_{s_i} z_{s_i}^\top$。 综合优先级分数为： $$ U_t(s) = f_{\theta_{t-1}}(z_s) + \nu \sqrt{z_s^\top A_{t-1}^{-1} z_s} $$ 每轮选择优先级最高的技能交由目标 Agent 执行；该分数也用于种群更新时识别并**剪除低价值技能**。 #### 2.2 基于证据的技能进化 种群以预定调度（对数间隔）进行更新，每次淘汰 $m$ 个低优先级技能，并通过三种算子生成新候选： - **再生（Regeneration）**：从无技能初始轨迹 $\mathcal{T}_0$ 独立生成新技能，引入全新搜索方向，维持多样性； - **Rollout 突变（Rollout Mutation）**：基于当前被评估技能的成功与失败轨迹进行局部精炼； - **交叉（Crossover）**：利用历史高/低性能技能分别作为正/负证据，对高性能骨干技能进行重组优化。 新技能不继承历史奖励，必须重新进入 bandit 评估循环。 --- ### 3. 实验与结果 论文在 **6 个异构基准**（SearchQA、SpreadsheetBench、DocVQA、LiveMath、SocialMaze、ALFWorld）和 **3 个目标模型**（Qwen3.6-35B-A3B、GPT-5.4-Nano、Gemma-4-26B-A4B-it）上进行了系统评估。 #### 3.1 主要性能 - COBRA-Skills 在全部三个目标模型上均取得最高平均性能，相比无技能基线分别提升 **13.1、26.9、22.5** 个百分点； - 与现有方法 SkillOpt 相比，总优化成本降低 **55%–58%**，单位性能提升成本降低 **60%–69%**； - 仅使用 **50 个优化样本/基准**，展现出极高的样本效率。 #### 3.2 泛化与鲁棒性 - **跨 Harness 测试**：在 Claude Code 和 Codex 外部执行接口上，优化后的技能仍保持领先性能； - **自教学设置**：将外部教师模型替换为目标模型自身后，性能仅轻微下降（73.5% → 72.5%），而成本降低约一半； - **跨模型迁移**：36 组跨模型迁移中 34 组优于对应无技能基线，表明技能捕获了任务级通用策略。 #### 3.3 消融分析 - 去除 bandit 引导（随机选择）或去除进化（固定候选池）均导致性能显著下降； - 简单扩大候选池至 30 个并选最优（Best-of-30）仍不及完整方法，证明 bandit 与进化的互补增益不可替代。 --- ### 4. 核心贡献 - **问题形式化**：首次将 Agent 技能优化建模为动态候选空间上的预算化顺序优化问题，明确评估预算与候选演化的耦合约束； - **算法设计**：提出 COBRA-Skills，通过神经上下文赌博机实现评估资源的自适应分配，并通过三种证据接地算子实现高效的种群进化； - **实验验证**：在多基准、多模型、多执行环境下验证了方法在性能、成本效率与样本效率上的全面优势。
