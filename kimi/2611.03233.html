Q1: 这篇论文试图解决什么问题？

该论文旨在解决**构建强大且具备广泛能力的智能体基础模型（agent foundation models）时训练流程日益复杂化**的问题，并探索一种更简洁、可复现且完全开放的替代路径。具体而言，论文针对以下核心问题展开： ## 1. 训练流程的过度复杂化 当前先进的智能体模型通常依赖愈发碎片化的训练栈，包括： - 持续预训练 / 中间训练（mid-training） - 多阶段监督微调（SFT） - 直接偏好优化（DPO） - 在线策略蒸馏（OPD） - 多轮后训练流程 这种复杂性使得研究者难以判断哪些环节真正必要，同时抬高了复现成本，并掩盖了能力增益的具体来源。 ## 2. "开放"模型的可复现性不足 许多所谓"开放"的模型仅发布权重，而隐藏了开发过程中的关键部分——包括数据构建、过滤、验证、提示词设计以及训练代码——导致其能力来源难以被检验和扩展。 ## 3. 如何在简化流程的同时保持强大能力 论文的核心假设是：**简化训练管线并不意味着简化学习问题本身**。通过将重心转移到高质量、具有挑战性且可自动验证的训练数据上，可以在大幅减少训练阶段的前提下，仍然获得强大的推理、工具使用与长程交互能力。 --- **总结来说**，该论文试图回答的问题是：**构建一个强大且具备广泛智能体能力的基础模型，是否真的需要如此复杂的训练流程？** 论文通过提出 **Axion 1.0** 表明，仅通过**两个轻量级SFT阶段 + 强化学习**的三阶段简洁配方，配合模型感知的数据构造与可扩展的确定性任务生成，即可在多项具有挑战性的推理与智能体基准上达到与顶尖商业模型相竞争的性能，同时实现训练过程的完全开放与可复现。

Q2: 有哪些相关研究？

根据论文第6节（Related Work）及全文引用，相关研究可分为以下五个方向： ## 1. 智能体基础模型（Agent Foundation Models） 该方向关注将推理、编码与工具使用整合为通用能力的研究，以及面向持续信息搜集与外部环境的科研型智能体： - **Kimi K2** [16] 与 **GLM-4.5** [11]：展示了将推理、编程与工具使用整合为通用能力的趋势。 - **MiroThinker-1.7** [22]：结合智能体中间训练（agentic mid-training）、SFT、偏好优化与RL构建重型研究智能体。 - **Agents-A1** [7]：采用长程监督与领域路由的在线策略蒸馏（domain-routed on-policy distillation）。 - **Apodex 1.1** [1]：研究可执行环境与智能体协作。 与上述工作相比，Axion 1.0 探索了**更简洁的训练序列**（两阶段SFT后接RL），不依赖专门的中间训练、DPO或OPD。 ## 2. 挑战性且可验证任务的构造（Construction of Challenging and Verifiable Tasks） 该方向涵盖从合成数据生成到面向学习者的自适应难度调整： - **Self-Instruct** [42]：利用模型输出生成指令数据。 - **Evol-Instruct** [46]：通过迭代变换提升任务复杂度。 - **Absolute Zero** [51]：基于执行环境的自我博弈（self-play）生成数据。 - **Agent0** [44]：通过任务生成器与工具使用智能体的交互自动构建课程。 - **TaskCraft** [38]：沿深度与广度扩展可验证的多工具任务。 - **WebShaper** [40]：结构化信息搜寻的复杂度。 - **QUEST** [45]：构建带有可验证评分标准（rubric）的深度研究任务。 Axion 1.0 在第一阶段借鉴了**模型反馈**思想，但针对性地强化基模型已能解决的问题；第二阶段则通过**确定性过滤、选择与计算**在结构化数据上预先生成参考答案，确保任务可验证且强制依赖工具检索。 ## 3. 面向推理与工具使用的强化学习（RL for Reasoning and Tool Use） 该方向关注将RL从单轮响应优化扩展到多步决策与工具交互： - **DeepSeek-R1** [9]：展示了RL在激发推理能力方面的潜力。 - **Search-R1** [15]：将RL扩展到与搜索引擎检索交错的推理过程。 - **DeepResearcher** [55]：在真实开放网络环境中通过RL训练智能体。 - **AgentGym-RL** [43]：跨环境的多样多轮RL学习。 Axion 1.0 在两阶段互补的SFT之后应用RL，基于已建立的推理与工具使用轨迹，进一步改进长程交互中的决策。 ## 4. RL中的训练-推理一致性（Training–Inference Consistency in RL） 该方向解决智能体RL中常见的推理引擎（生成轨迹）与训练后端（计算策略更新）之间的不匹配问题： - **重要性采样截断、序列感知掩码与token级修正分析** [17, 47, 54, 56]：从算法层面分析并缓解由系统差异导致的离策略问题。 - **专家路由重放（Rollout Routing Replay, R3）** [20]：在MoE模型中记录并回放推理阶段的路由决策，对齐训练与推理的路由器。 - **数值格式选择与精度感知优化** [32, 50]：减少因数值表示差异造成的概率不匹配。 - **Token-In-Token-Out（TITO）** [37]：在智能体循环中直接传递token ID，避免解码-再编码引入的token化错位。 Axion 1.0 同时采用了 **TITO** 与 **R3**，分别处理token序列一致性与MoE专家路由一致性。 ## 5. 开放且可复现的训练配方（Open and Reproducible Training Recipes） 该方向强调超越权重发布的全流程开放： - **OpenThoughts** [13]：开发开放的推理数据配方。 - **OpenThoughts-Agent** [34]：研究并发布智能体数据整理流程。 - **DR Tulu** [36]：提供面向研究智能体的开放RL框架。 - **QUEST** [45]：发布模型、数据与训练脚本。 Axion 1.0 延续了这一方向，完整发布其三阶段配方，包括数据生成、过滤、验证、提示词与训练代码，以支持可复现与可扩展的智能体基础研究。

Q3: 论文如何解决这个问题？

该论文通过**简化训练管线**、**强化数据构造质量**与**保障全流程开放**三位一体的策略，解决了智能体基础模型训练流程过度复杂且难以复现的问题。具体解决方案如下： ### 1. 极简的三阶段训练配方 Axion 1.0 将训练流程压缩为仅三个连续阶段，去除当前主流方案中常见的 dedicated mid-training、Direct Preference Optimization（DPO）与 On-Policy Distillation（OPD）等环节： - **Stage I SFT**：在自包含推理数据上微调，建立多步科学推理与计算能力； - **Stage II SFT**：在工具依赖推理数据上继续微调，将自包含推理扩展至检索、网页浏览与 Python 计算等外部交互； - **RL**：基于 GRPO 进一步巩固长程工具交互与决策能力。 这一设计将能力来源从“流程堆叠”转移到“数据质量与阶段递进”，显著降低了复现门槛。 ### 2. 模型感知的自包含推理数据构造（Stage I） 为了避免在简单或低质量数据上训练，论文提出基于基模型能力反馈的对抗式数据增强： - **种子问题**：采集公开课程、竞赛及推理数据集中的数学、物理、化学、生物与计算机科学问题； - **初始增强**：通过**组合（Composition）**操作生成依赖原问题答案作为中间步骤的新问题； - **针对性强化**：利用基模型评估增强后的问题。若基模型能正确解答，则根据其成功解题策略，随机施加四种变换之一进一步增难： - **A. 组合**：再增加一层依赖推理； - **B. 参数化**：将固定数值替换为符号参数，要求通式而非数值； - **C. 范围偏移**：扩大参数范围，使枚举或捷径失效； - **D. 案例分析**：引入分情况讨论的条件。 - **独立验证**：每个新问题均由 GPT-5.5 独立求解三次，仅当三者答案与推导均一致时才采纳为训练数据。 由此构造的数据集 $$\mathcal{D}_{\text{sc}} = \{ (x_i, \tau_i, \emptyset, y_i) \}_{i=1}^{M_{\text{sc}}}$$ 确保问题难度与基模型当前能力精准匹配。 ### 3. 可扩展且强制工具依赖的任务构造（Stage II） 针对需要外部信息的任务，论文设计了“先构造答案、后生成问题”的确定性流程，确保任务可自动验证且必须依赖工具： - **四步构造（Filter–Select–Compute–Verbalize）**： 1. **Filter**：按显式条件过滤结构化数据库中的记录； 2. **Select**：依据极值等准则选定唯一实体； 3. **Compute**：通过确定性公式计算导出量（含单位换算），生成参考答案； 4. **Verbalize**：由 LLM 将条件与计算请求转化为自然语言问题，但隐藏选定的实体与答案。 - **强制工具依赖**：构造时使用的数据库在解题阶段被屏蔽，仅保留通用搜索、网页访问与 Python 执行权限；同时过滤掉闭卷即可正确回答的问题，确保模型必须检索外部证据。 - **轨迹过滤**：仅保留最终答案正确、工具调用规范且格式完整的交互轨迹。数据集表示为 $$\mathcal{D}_{\text{ta}} = \{ (x_i, \tau_i, z_i, y_i) \}_{i=1}^{M_{\text{ta}}}$$ 其中 $z_i$ 包含构造阶段记录的中间验证目标。 ### 4. 结合结果与过程奖励的强化学习 从 Stage II 检查点出发，论文采用 GRPO 优化模型自主生成的工具交互轨迹，并设计了细粒度奖励机制： - **奖励函数**： $$ R(\tau; y, z) = \begin{cases} 1, & F = 1, \\ \max(0, 0.3P - 0.1(1-A)), & F = 0. \end{cases} $$ 其中 $F(\tau; y)$ 表示最终答案正确性，$A(\tau)$ 表示是否提交了有效答案，$P(\tau; z)$ 衡量中间过程进度。 - **过程奖励按依赖链聚合**： 对于包含 $m$ 个有序中间目标的验证链，过程奖励为 $$ P(\tau; z) = \frac{1}{m} \sum_{j=1}^{m} \prod_{\ell=1}^{j} b_\ell(\tau; z), $$ 其中 $b_\ell(\tau; z) \in \{0,1\}$ 表示第 $\ell$ 个中间目标是否正确达成。该设计确保后续步骤仅在所有前置步骤完成时才能获得信用。 - **任务筛选**：仅保留至少有一条轨迹达到正确答案且组内奖励方差非零的问题，以保证有效的组相对学习信号。 ### 5. 训练基础设施的一致性保障 针对智能体 RL 中推理引擎与训练后端常见的概率不匹配问题，论文引入了两项关键对齐技术： - **Token-In-Token-Out（TITO）**：在智能体循环中直接传递 token ID，避免对工具输出进行解码-再编码所导致的 BPE 切分错位，确保训练与推理见到的 token 序列完全一致。 - **Rollout Routing Replay（R3）**：对于 MoE 模型，记录推理阶段（vLLM）每 token 在每层的路由专家，并在训练前向（Megatron）中重放。这减少了专家路由差异导致的梯度方差与 KL 漂移，提升策略优化的稳定性。 在 SFT 阶段，论文采用 FSDP 配合专家并行与上下文并行（Ring Attention / Ulysses），以完整长轨迹（长达 128K tokens）作为训练样本，避免上下文压缩造成的信息损失。 ### 6. 完全开放的开发配方 为了解决“仅开放权重”导致的不可复现问题，论文发布了超越模型权重的完整资产： - 数据构造、生成、过滤与验证的完整流程与代码； - 所有提示词（prompts）与中间验证规则； - SFT 与 RL 的训练代码及超参数； - 模型检查点与评估协议。 通过上述策略，Axion 1.0 证明了：**强大的智能体能力可以通过精简的训练管线与精心构造的数据获得**，而无需依赖日益碎片化的后训练流程。

Q4: 论文做了哪些实验？

论文在第 4 节（Evaluation）及附录中开展了一系列实验，从**整体性能对标**、**训练阶段消融**、**规模与初始化分析**以及**基础设施组件验证**四个维度评估 Axion 1.0。具体实验内容如下： --- ### 1. 整体智能体性能对标 在六个覆盖通用推理、科学研究、信息检索与智能体问题求解的基准上，将 Axion 1.0-35B 与 Axion 1.0-122B 同当前主流开源权重模型及前沿商业模型进行全面对比： - **Humanity’s Last Exam (HLE)**：跨学科专家级问题求解 - **BioMysteryBench (BMB)**：真实生物数据分析（human-difficult 子集） - **SEAL-0**：信息检索与搜索增强推理 - **HiPhO**：高中物理奥林匹克级别科学推理 - **FrontierScience Olympiad**：前沿科学奥林匹克推理 - **FrontierScience Research**：前沿科学研究任务 实验结果显示，Axion 1.0-122B 在 HLE 上达到 59.0%（受限访问条件下），在 FrontierScience Research 上达到 66.7%，在多项基准上超越或逼近 GPT-5.6 Sol、Claude Opus 5 等商业模型。 --- ### 2. 各训练阶段的逐层贡献分析 为验证三阶段配方的有效性，论文追踪了**同一基模型**从初始化检查点到完成 Stage I、Stage II 及 RL 后的性能变化。该实验并非严格的组件移除消融，而是按时间顺序展示能力累积： - **Stage I（自包含推理 SFT）**：在 HLE-130、HiPhO 与 FrontierScience Olympiad 上带来最大提升，表明该阶段有效强化了多步科学推理与计算能力。 - **Stage II（工具依赖推理 SFT）**：在 BMB、FrontierScience Research 与 SEAL-0 上增益显著，验证了从独立推理向信息检索与证据计算过渡的有效性。 - **RL**：在 HLE-130 与 SEAL-0 上进一步取得一致提升；对科学推理基准的增益因模型规模而异，122B 模型在 BMB 与 FrontierScience Research 上均有所改善。 实验基线包括 Qwen3.6-35B-A3B 与 Qwen3.5-122B-A10B 的原始检查点，评估采用 130 题的 HLE 文本子集（HLE-130）以控制成本。 --- ### 3. 基模型选择的影响 论文在相同的两阶段 SFT 配方下，对比了两种 35B-A3B 初始化（Qwen3.6-35B-A3B 与 Qwen3.5-35B-A3B）在训练前后的表现： - 训练前，Qwen3.5 在六项基准中的五项上落后于 Qwen3.6（如 HLE-130 差距达 9.2%）。 - 经过相同的 Stage I + Stage II SFT 后，二者差距大幅收窄（HLE-130 差距降至 0.8%；BMB 持平于 35.3%）。 该实验表明，所构造的 SFT 数据对不同的初始检查点均有效，而非仅依赖于更强的基模型。 --- ### 4. 模型规模扩展实验 为检验数据配方的跨规模迁移性，论文在 4B、9B、35B 与 122B 参数规模上进行了实验： - **4B 与 9B（仅两阶段 SFT，无 RL）**：9B 模型在所有六项基准上均优于 4B。例如，HLE-130 从 53.1% 提升至 63.1%，FrontierScience Research 从 45.0% 提升至 55.0%。这说明构造的数据对较小模型同样有效。 - **35B 与 122B（完整三阶段）**：随着规模增大，五项基准得分提升，其中 FrontierScience Research（+10.0%）、HLE（+6.8%）与 BMB（+6.4%）增幅最大。 需注意，35B 与 122B 结果并非严格的受控规模缩放实验，因其 additionally 经过了 RL 且采用了不同的基础架构。 --- ### 5. RL 的跨规模效果分析 通过对比 35B 与 122B 模型在 RL 前后的检查点，论文分析了强化学习在不同规模下的作用： - **Axion 1.0-35B**：RL 在 SEAL-0（+9.0%）与 HLE-130（+3.8%）上增益最大；在 BMB 上无变化，在 HiPhO 与 FrontierScience Research 上略有下降。 - **Axion 1.0-122B**：RL 在 BMB（+6.4%）、HLE-130（+6.1%）与 SEAL-0（+5.4%）上增益显著，且在 HiPhO 与 FrontierScience 两项上均有小幅提升。 该实验说明 RL 对信息检索类与综合推理类任务具有一致增益，而对特定科学推理基准的影响与模型规模相关。 --- ### 6. Rollout Routing Replay (R3) 的验证实验 在 Qwen3.5-122B-A10B 上，论文对比了启用与禁用 R3 的 RL 训练动态及下游性能： - **训练动态指标**：启用 R3 后，序列平均对数概率差距从 0.044 降至 0.042，最大差距从 1.799 降至 1.282；平均梯度范数从 1.998 降至 1.922，平均 PPO KL 从 0.0413 降至 0.0396，平均裁剪比例从 3.86% 降至 3.68%。 - **下游性能**：启用 R3 后，HLE-130 从 72.3% 提升至 74.6%，FrontierScience Olympiad 从 85.0% 提升至 87.0%，FrontierScience Research 从 61.7% 提升至 66.7%。SEAL-0 则从 63.1% 降至 58.6%。 该实验为 R3 改善 rollout–trainer 一致性提供了证据，同时指出部分基准表现的变化也可能受到异步策略陈旧与上下文压缩离策略效应的混杂影响。 --- ### 7. 定性案例研究（附录 B） 除上述定量实验外，论文在附录中提供了三个跨越训练阶段的定性轨迹对比，以展示行为演进： | 过渡阶段 | 任务类型 | 展示能力 | |---|---|---| | Base → Stage I | 立方体表面测地线距离 | 检测数值近似缺陷并修正解法 | | Stage I → Stage II | 哲学概念归属查询 | 检索并直接引用支持性文献段落 | | Stage II → RL | 印度打车软件识别 | 分离冲突的使用指标并依据题目准则进行综合判断 | 这些案例补充了表格中的聚合统计，具体说明了自检查、证据锚定检索与冲突信息综合等智能体行为如何随训练逐步涌现。

Q5: 有什么可以进一步探索的点？

基于论文所呈现的方法与结果，以下几个方面值得进一步探索： ### 1. 训练配方的极限压缩与组件必要性分析 - **单阶段联合训练的可行性**：论文将 SFT 拆分为自包含推理与工具依赖推理两个阶段。可探索是否能在**单一阶段**内通过混合数据直接习得两种能力，从而进一步压缩训练流程。 - **纯 RL 冷启动**：验证模型能否在**无 SFT 预热**的情况下，仅通过可验证奖励的强化学习直接习得工具使用与复杂推理，这将极大简化训练栈。 - **DPO/OPD 的真实增益边界**：论文刻意排除了 DPO 与 OPD，未来可在相同数据与评估协议下，严格量化加入这些组件后的边际收益，验证其是否真的“不必要”。 ### 2. 数据构造方法的自动化与领域扩展 - **自适应难度变换策略**：Stage I 目前使用固定的四种增强操作（Composition、Parameterization、Range Shift、Case Analysis）。可引入**自动化的课程学习**或对抗式生成网络，让数据生成器根据模型实时能力动态选择最优变换组合，而非随机选择。 - **非结构化与多模态数据源**：当前 Stage II 依赖结构化数据库（如天文、化学记录）。可扩展至**半结构化数据**（科研论文、PDF报表）及**多模态内容**（图表、分子结构图像），构造需要视觉理解或跨文档推理的工具使用任务。 - **开放式问题的验证机制**：现有配方强依赖确定性答案验证。对于 FrontierScience Research 等开放式科研任务，可探索基于**LLM-as-Judge 的鲁棒 rubric 自动生成**与**人类专家校准**，使 RL 能扩展到无唯一标准答案的领域。 ### 3. 奖励设计与过程监督的精细化 - **自动里程碑发现**：当前过程奖励 $P(\tau; z)$ 依赖人工预设的中间验证目标 $z$。可研究如何从构造程序或专家演示中**自动提取中间里程碑**，减少人工设计成本。 - **细粒度错误定位**：探索在错误轨迹上施加**基于 Credit Assignment 的负向信号**（例如定位首次出现逻辑错误的步骤），而非仅给予零奖励或简单惩罚，以提高样本效率。 - **稀疏奖励下的长程 RL**：验证在仅提供最终答案正确性（$F=1/0$）的极端稀疏设置下，配合大规模预训练与上下文压缩，GRPO 是否仍能收敛，从而验证过程奖励的必要性边界。 ### 4. 规模、架构与跨模型迁移的受控研究 - **严格的规模缩放实验**：论文中 4B/9B 与 35B/122B 并非严格对照（基座架构与是否经历 RL 均不同）。需在**同架构系列**上执行控制实验，精确量化参数规模与 RL 阶段的交互效应。 - **配方跨架构迁移性**：验证 Axion 的三阶段配方在 Llama、Mixtral 或其他非 Qwen 架构上的有效性，检验其是否为通用训练法则还是特定于 Qwen 的优化路径。 - **MoE 与 Dense 模型的对比**：在相同激活参数量下，比较 MoE（如 122B-A10B）与 Dense 模型在该配方下的训练稳定性、工具调用一致性与最终性能差异。 ### 5. 工具生态的扩展与复杂协同 - **多工具链与状态ful 环境**：当前工具集主要涵盖搜索、网页访问与 Python。可引入 SQL 数据库查询、代码解释器、浏览器自动化（如执行 JavaScript）及**多步骤状态维护**，训练模型处理需要跨工具保持上下文的复杂工作流。 - **工具错误恢复与探索**：现有数据过滤仅保留正确轨迹。未来可探索**从失败轨迹中学习**（例如网页超时、Python 报错后的自我修正），提升模型在真实 noisy 环境中的鲁棒性。 ### 6. 训练-推理一致性与系统优化 - **消除异步策略陈旧**：论文指出 R3 与 TITO 缓解了部分不一致性，但异步 RL 中的权重同步延迟（45–60 秒）与策略陈旧仍是混杂因素。可探索**同步 rollout-training** 架构或低延迟参数同步协议（如参数服务器广播），以隔离一致性改进的因果效应。 - **上下文压缩与信息保全的权衡**：QUEST 式的上下文压缩虽支持长程交互，但可能丢失早期细节。可研究**动态、可逆的层次化记忆机制**（如摘要树、可检索的 checkpoint），替代硬截断或压缩。 ### 7. 安全性、对齐与数据污染防控 - **工具使用的安全对齐**：智能体可执行代码与访问网络，带来了提示注入、恶意代码执行等风险。可在三阶段配方中嵌入**安全约束 RL**（Constrained RL）或**红队对抗数据**，在不牺牲推理能力的前提下约束危险行为。 - **大规模构造中的污染检测**：随着数据构造规模扩大，需建立更严格的**去污染与记忆检测机制**（如 n-gram 回溯、embedding 相似性审计），防止训练数据与下游评估基准发生隐式重叠。 ### 8. 计算效率与实用部署 - **参数高效微调（PEFT）替代全参数 SFT**：Stage I 与 Stage II 目前采用全参数微调。可验证 LoRA、DoRA 等 PEFT 方法在保持同等 agentic 能力的同时，能否进一步降低训练成本与检查点存储开销。 - **RL 阶段的采样效率优化**：当前每问题使用 8 条 rollout。可探索通过**重要性采样校正**或**模型-based 价值估计**，将必要 rollout 数降至 2–4 条，显著削减 RL 阶段的 GPU 消耗。

Q6: 总结一下论文的主要内容

该论文介绍了 **Axion 1.0**，一个完全开放、训练流程极简但能力强大的智能体基础模型（agent foundation model）。其核心主张是：通过精心设计的高质量数据与清晰的阶段化学习，而非堆砌复杂的后训练环节，即可构建具备广泛智能体能力的模型。 ## 1. 核心动机 当前智能体模型的训练流程日趋复杂，通常涉及持续预训练、多阶段 SFT、DPO、OPD、RL 等多个碎片化环节，导致复现困难、能力来源不明。同时，许多所谓“开放”模型仅发布权重，隐藏了数据构造与训练细节。Axion 1.0 旨在证明：**强大的智能体基础模型可以既简单又完全开放**。 ## 2. 极简三阶段训练配方 Axion 1.0 采用仅有三个阶段的紧凑流程，**不引入专门的 mid-training、DPO 或 OPD**： - **Stage I SFT（自包含推理）**：教导模型利用题目给定信息进行多步科学推理与计算； - **Stage II SFT（工具依赖推理）**：教导模型通过搜索、网页浏览、Python 等外部工具获取缺失信息，并基于证据完成推理； - **RL（强化学习）**：基于模型自主生成的长程工具交互轨迹，通过 GRPO 进一步优化决策与推理。 ## 3. 模型感知的数据构造 论文将能力增益的来源从“训练流程复杂度”转向“数据质量”。 **Stage I：自包含推理数据** - 以公开课程与竞赛题为种子，首先通过**组合（Composition）**生成初始难题； - 利用基模型进行能力诊断：若基模型能正确解答，则根据其成功策略，随机施加四种对抗性变换之一进一步增难： - **A. 组合**：增加一层推理依赖； - **B. 参数化**：将固定值替换为符号参数； - **C. 范围偏移**：扩大参数范围使枚举失效； - **D. 案例分析**：引入需分情况讨论的条件。 - 每个问题均经独立验证（GPT-5.5 三次一致求解）后才纳入训练。 **Stage II：工具依赖推理数据** - 基于结构化公开数据库，采用**Filter–Select–Compute–Verbalize**四步确定性流程构造问题： 1. 按条件过滤记录； 2. 按极值等准则选定唯一实体； 3. 通过确定性公式计算导出量，生成参考答案； 4. 由 LLM 将条件转化为自然语言问题，同时隐藏答案与数据库访问路径。 - 在解题阶段屏蔽构造时使用的数据库，并过滤掉闭卷可解的问题，强制模型必须进行真实的信息检索与计算。 ## 4. RL 奖励设计 强化学习阶段使用兼具结果与过程监督的奖励： - **结果奖励**：最终答案正确则 $R=1$； - **过程奖励**：针对具有中间验证目标 $z = \{v_1, \dots, v_m\}$ 的任务，定义 $$ P(\tau; z) = \frac{1}{m} \sum_{j=1}^{m} \prod_{\ell=1}^{j} b_\ell(\tau; z), $$ 其中 $b_\ell(\tau; z) \in \{0,1\}$ 表示第 $\ell$ 个中间目标是否正确达成。后续步骤仅在所有前置步骤完成时才能获得信用，形成依赖链式的部分奖励。 - **非提交惩罚**：若未给出有效最终答案，即使取得部分进展也会受到惩罚，鼓励模型完成完整推理。 ## 5. 基础设施与一致性保障 为支撑长程智能体轨迹的训练，论文引入两项关键对齐技术： - **Token-In-Token-Out (TITO)**：在智能体循环中直接传递 token ID，避免解码-再编码导致的 token 边界错位，确保训练与推理的 token 序列完全一致； - **Rollout Routing Replay (R3)**：记录推理阶段 MoE 模型的专家路由决策并在训练前向中重放，减少推理引擎（vLLM）与训练后端（Megatron）的路由不一致，稳定 RL 优化。 SFT 采用 FSDP + 专家并行 + 上下文并行（Ring Attention / Ulysses），支持最长 128K token 的完整轨迹训练；RL 采用异步 GRPO 架构，分离 rollout 生成与策略优化。 ## 6. 实验结果 论文在六个挑战性基准上评估了 Axion 1.0： - **Humanity’s Last Exam (HLE)**：122B 模型达到 **59.0%**（受限访问），与 Claude Opus 5（63.6%）、Claude Fable 5（63.8%）处于同一水平区间； - **SEAL-0**（信息检索）：35B 模型达到 **62.2%**，超越 Agents-A1（56.4%）等同类模型； - **FrontierScience Research**（科学研究）：122B 模型达到 **66.7%**，超过 GPT-5.6 Sol（63.3%）； - **HiPhO** 与 **FrontierScience Olympiad**：在科学推理与奥林匹克级别问题上表现强劲。 **阶段贡献分析**显示： - Stage I 主要提升自包含科学推理（HLE-130、HiPhO、FrontierScience Olympiad）； - Stage II 主要提升工具使用与信息分析（BMB、FrontierScience Research、SEAL-0）； - RL 在两类任务上进一步提供一致增益，尤其对更大模型（122B）的增益更稳定。 **跨规模与跨初始化实验**表明，该数据配方对 4B、9B、35B、122B 均有效，且对 Qwen3.5 与 Qwen3.6 两种基模型初始化均能产生显著提升。 ## 7. 完全开放的发布 Axion 1.0 不仅发布模型权重，还完整开源了： - 数据构造、生成、过滤与验证的代码与流程； - 所有提示词与中间验证规则； - SFT 与 RL 的训练代码及超参数。 论文最终证明：通过精心构造的数据、清晰的能力递进阶段，以及简洁的 RL 优化，即可在广泛且具挑战性的智能体任务上达到前沿水平，而无需依赖日益复杂的训练管线。这为开放、可复现的智能体基础研究提供了一条实用路径。
