Q1: 这篇论文试图解决什么问题？

这篇论文致力于解决**递归自我改进（Recursive Self-Improvement, RSI）框架下的显式世界模型学习问题**，即让基于冻结大语言模型（frozen LLM）的智能体在持续交互中自主推断、表示并修正其对陌生环境动态的理解。 具体而言，论文针对以下核心挑战： - **从有限交互中学习可泛化的环境规则** 智能体进入未知环境时，既不了解对象与动力学，也不清楚成功标准。有限的交互历史通常支持多个程序假设（version space），这些假设在已观察到的状态转移上一致，但在未观察状态上预测相异。如何在这些竞争中识别并维护正确的泛化假设，是一个根本难点。 - **策略记忆到语义世界模型的扩展** 此前的 Memento 系列主要聚焦于策略与程序记忆（学习“该做什么”），而 MEMENTO 3 将反思式学习扩展到**模型侧**（学习“世界如何运转”）。智能体需要一种显式的、可修订的语义记忆载体，来记录关于实体、动作语义、动力学和目标的假设，并让这些假设能够指导规划与探索。 - **确保模型忠实性与可验证性** 自然语言描述与可执行代码之间可能存在偏差。论文要求世界模型不仅要在语言层面记录规则（rulebook），还要能编译成可执行程序（executable），并通过**精确重放（exact replay）**验证其是否与全部观察历史一致，从而以执行结果约束语言模型的生成不确定性。 - **避免单一假设的自确认陷阱** 若智能体过早承诺于一个与当前证据一致但实质错误的模型，其后续规划可能永远避开能证伪该模型的证据。论文通过引入**多模型种群（population extension）**机制，并行维护多个通过共享交互历史更新的规则书–可执行程序对，以保留行为多样性并引导更有效的探索。 简言之，论文试图建立的机制是：在**不更新底层 LLM 参数**的前提下，让智能体通过外部记忆持续构建、编译、验证并修订其世界模型，使该模型同时成为**学习的对象**与**学习的工具**，从而在基于模型的规划、探索与证据积累之间形成递归改进的闭环。

Q2: 有哪些相关研究？

根据论文第6节及全文的讨论，相关研究可归纳为以下五个方向： ### 1. 世界模型与可执行表示 - **经典模型学习与规划**：Dyna 将真实交互与模型生成的经验相结合，用于规划与学习 [38]；神经世界模型则通过潜在表示支持想象推演、模型预测控制与树搜索 [6, 14, 35]。 - **语言引导的程序归纳**：Parsel 利用自然语言分解配合基于执行的测试 [47]；Hypothesis Search 将语言假设转化为程序并在输入-输出示例上验证 [43]。 - **交互式环境建模**：WorldCoder 学习 Python 动力学模型并依据观察到的反例进行修复 [39]；GIF-MCTS 通过生成、改进与修复循环搜索候选模型 [8]；Code World Models for General Game Playing 从规则与轨迹中构建转移、合法性与终止函数以支持蒙特卡洛树搜索 [21]；Code-as-World 进一步将可执行建模扩展到物理推理领域 [41]。 - **多模态语言模型**：Dynalang 将语言作为预测模态纳入多模态潜在模型 [22]。 ### 2. ARC-AGI-3 中的模型构建、验证与动作选择 - **持久化可执行模型**：Rodionov 的 baseline1 维护、简化并验证持久的 Python 模型，再通过其进行规划 [30]；后续组件研究检验了精确重放与可执行模型对动作性能的影响 [29]。 - **假设驱动的探索**：OPINE-World 维护自然语言假设，合成以对象为中心的可执行模型，并利用本体论误差指导探索，要求候选程序精确复现记录的转移 [7]。 - **数字孪生与主动抽象**：Twin 通过交互历史的重放来约束基于模型的动作选择 [37]；Tycho 则研究智能体应在何时构建、修复、使用或绕过可执行模型，指出更好的转移重放并不必然带来更优决策 [20]。 ### 3. 语言规则与反思记忆 - **文本化记忆与规则手册**：Reflexion 存储关于任务反馈的语言反思以改进后续决策 [36]；AutoManual 通过交互环境学习归纳并组织可重用的规则手册 [4]；WALL-E 通过比较预测与观察轨迹来更新和修剪符号规则，从而对齐 LLM 世界模型与环境 [50]。 - **Memento 系列**：从基于情景记忆的持续适应 [48]，到形式化为状态化反思学习（将记忆写入/读取解释为策略评估与改进）[42]，再到 Memento-Skills 构建可重用的程序记忆 [49]。本文的 MEMENTO 3 将这一脉络扩展至**语义世界模型记忆**，以规则手册及其可执行实现作为显式的环境规范。 ### 4. 模型不确定性与探索 - **版本空间与简洁性偏好**：Version spaces 形式化了有限证据下剩余的假设歧义 [24, 25]；最小描述长度（MDL）原则为一致性假设提供了简洁性偏好的理论依据 [28]。 - **基于模型的强化学习中的不确定性**：通过概率动力学模型或模型集成来表示不确定性 [6, 19]。 - **后验采样与集成采样**：Posterior sampling 及其变体通过在一段交互内保留采样得到的模型或价值函数，支持时间上一致的深度探索 [23, 26, 27]。本文的**种群扩展（population extension）**即受此启发，通过并行维护多个共享交互历史的规则书–可执行程序对来降低对单一初始模型的依赖。 ### 5. 持续智能体适应与外部学习状态 - **工作空间与脚手架优化**：DreamTeam 中的 Workspace Optimization 让专门智能体负责构建模型、探测假设与规划 [33]；Continual Harness 支持提示、子智能体、技能与记忆的在线修订 [17]。 - **面向对象与信念校准**：NOOA 结合 Python 面向对象接口、持久可执行模块与预测误差驱动的细化 [13]；Belief-Calibrated Optimization 维护关于评估函数如何响应智能体提示变化的语言世界模型，用于指导对智能体自身的编辑 [5]。 - **无生成模型的探索**：基于图的探索方法记录观察到的状态转移并优先测试未尝试的动作，无需显式生成世界模型 [32]。

Q3: 论文如何解决这个问题？

论文通过 **MEMENTO 3** 框架解决上述问题，其核心是 **Code as Model** 设计——将智能体的世界模型表示为一对互补的外部记忆产物：一份自然语言规则书（rulebook）及其可执行实现（executable）。整个系统在底层大语言模型（LLM）参数完全冻结的前提下，通过持续的“观察–反思–修订–编译–验证”闭环实现模型侧的递归自我改进。 ### 1. 双组件表示：规则书与可执行代码 智能体的外部学习状态由交互历史与当前世界模型假设共同构成： $$Z_t = (H_t, \psi_t, \theta_t)$$ 其中： - **$H_t$** 为截至时刻 $t$ 的交互记录（动作–观察序列）； - **$\psi_t \in \Psi$** 是自然语言规则书，作为持久语义记忆，记录智能体对环境中实体、动作语义、动力学、目标及终止条件的当前假设； - **$\theta_t \in \Theta$** 是可执行程序（如 Python 模块），作为规则书的操作化实现，提供内部状态空间 $\hat{S}_\theta$、状态初始化器 $\iota_\theta$、转移预测器 $f_\theta$、观察渲染函数 $\rho_\theta$ 以及目标集合 $\hat{G}_\theta$。 规则书允许对未观察到的机制保持欠规定（underspecified），而可执行代码则必须对预测和规划给出确定性的操作定义。两者的语义一致性记为 $\theta \in [\![\psi]\!]$。 ### 2. 五阶段持续反思学习循环 每当智能体执行动作 $a_t$ 并获得新观察 $o_{t+1}$，系统即触发更新算子 $U$，包含以下五个阶段（见图 2）： #### （1）观察（Observation） 交互记录被扩展： $$H_{t+1} = H_t \parallel (a_t, o_{t+1})$$ #### （2）反思（Reflection） 冻结的 LLM 根据更新后的历史与当前模型对 $(\psi_t, \theta_t)$，诊断预测误差的来源，并在三种修订策略中选择： - **retain**：保留当前模型； - **revise_rulebook**：规则理解有误，需修改规则书； - **repair_code**：规则正确但实现有误，仅修复代码。 #### （3）规则修订（Rule Revision） 若反思选择修订规则书，LLM 基于新证据生成候选规则书 $\tilde{\psi}_{t+1}$；否则保留原规则书。规则书的变更必须显式记录智能体对环境理解的改变。 #### （4）编译（Compilation） 若需修订规则或修复代码，LLM 充当规则书引导的编译器 $C_\phi$，将（候选）规则书编译为候选可执行程序： $$\tilde{\theta}_{t+1} \sim C_\phi(\cdot \mid \theta_t, \tilde{\psi}_{t+1}, H_{t+1})$$ #### （5）验证（Verification） 候选对 $(\tilde{\psi}_{t+1}, \tilde{\theta}_{t+1})$ 必须通过两项检查方可被接受： - **精确重放（Exact Replay）**：用 $\tilde{\theta}_{t+1}$ 从初始观察开始重放全部历史动作，要求预测的每一个下一观察与真实记录完全一致： $$\text{verify}(\theta; H_t) = \prod_{i < t} \mathbb{1}\big[\hat{o}_\theta(H_i, a_i) = o_{i+1}\big] = 1$$ - **规则书忠实性（Rulebook Fidelity）**：LLM 评估源代码是否忠实实现了规则书中的自然语言规则，即 $\tilde{\theta}_{t+1} \in [\![\tilde{\psi}_{t+1}]\!]$。 只有同时满足两项条件的候选对才进入可接受集 $V_{t+1}$，并被采纳为 $h_{t+1} = (\psi_{t+1}, \theta_{t+1})$。若验证失败，系统返回反思阶段重新诊断。 ### 3. 基于验证模型的信念近似与规划 被接受的可执行程序通过重放历史重建当前内部状态 $\hat{s}_{\theta_t}(H_t)$。在单模型情形下，智能体使用点质量分布近似联合信念： $$\hat{b}_t = \delta\big(h_t, \hat{s}_{\theta_t}(H_t)\big)$$ 规划转化为在确定性内部模型上的最短路径搜索。定义值函数： $$V_\theta(x) = \begin{cases} 0, & x \in \hat{G}_\theta, \\ 1 + \min_{a \in A} V_\theta\big(f_\theta(x, a)\big), & \text{otherwise}. \end{cases}$$ 智能体从重建状态 $\hat{s}_{\theta_t}(H_t)$ 出发搜索有限动作序列以到达目标，并执行计划的首个动作。若无可行计划，则触发基于规则书不确定性的探索（如测试未解释的机制）。 ### 4. 种群扩展：从单一假设到并行多模型 为缓解单一模型可能陷入自确认（self-confirming）回路的局限，论文提出维护 $N$ 个并行的规则书–可执行程序对： $$\Phi_t = \{(\psi_t^i, \theta_t^i)\}_{i=1}^N \subseteq V_t$$ 所有成员共享同一交互历史 $H_t$，但可编码关于环境的不同假设。行动选择时，系统按行为等价类均匀采样：若多个成员生成了不同的非空行动计划，则随机选择一个行为类别执行。新观察会同时用于检验所有成员，预测冲突者进入修复流程。对应的经验信念近似为： $$\hat{b}_t^{(N)} = \frac{1}{N} \sum_{i=1}^N \delta\big(h_t^i, \hat{s}_{\theta_t^i}(H_t)\big)$$ 此设计保留了探索多样性，降低了对单一随机初始假设的依赖。 ### 5. 工程实现与领域适配 - **ARC-AGI-3**：规则书存储为 `world_model.md`，可执行实现为 `world_model_engine.py`。验证要求重放时预测的 $64 \times 64$ 网格与真实帧逐单元格精确匹配。整个规则书与代码的历史通过 Git 仓库留存，智能体可调阅早期版本以恢复或比较假设。 - **Atari Pong**：将离散的层级求解规划器替换为基于学习模型的反馈控制器。控制器利用世界模型预测球与对手拍的动力学，在不调用 LLM 的情况下实时选择动作，经学习后在三个不同开局的评估中均以 21:0 获胜。 通过上述机制，MEMENTO 3 使冻结 LLM 智能体能够自主地将交互证据转化为显式、可检验、可修订的世界模型，并用验证后的模型指导后续交互与进一步学习，从而形成模型侧的递归自我改进闭环。

Q4: 论文做了哪些实验？

论文在两类环境中开展了系统实验：以 **ARC-AGI-3** 为主的离散交互式谜题求解，以及 **Atari Pong** 上的连续反馈控制案例研究。具体实验内容如下： ### 1. ARC-AGI-3 主实验 **实验设置** - 在全部 **25 个公开 ARC-AGI-3 游戏** 上进行评估（见图 6）。 - 智能体仅观察动作接口与交互历史，不可访问环境源码或自然语言任务描述。 - 使用 Claude Opus 5 作为骨干模型，推理强度设为 extra-high。 - 以 **Relative Human Action Efficiency (RHAE)** 为主要指标，同时记录通关关卡数与实际动作数。 - 与人类动作基线及五个已发表基线系统对比：baseline1 [30]、NOOA [13]、OPINE-World [7]、DreamTeam [33]、Continual Harness [17]。 **主要结果** - 单模型智能体（$N=1$）**通关全部 25 个游戏的所有 183 个关卡**，平均 RHAE 达到上限 **100.0**。 - 总计使用 **7,518 个动作**，为人类基线（17,135 动作）的 **44%**；单游戏动作比介于 0.20（m0r0）至 0.67（lf52）之间。 - 作为参照，baseline1 同样通关 25 个游戏，平均 RHAE 为 99.0，动作总数 8,347；其余基线均存在未通关游戏（见表 1、表 2）。 ### 2. 消融实验：移除自然语言规则书 为隔离规则书 $\psi$ 的贡献，论文在保持框架、重放验证器、规划器、骨干模型及推理强度完全不变的前提下，**移除规则书更新循环**，仅保留代码世界模型。 **实验设计** - 从三个难度带中各选一局游戏： - **ft09**（简单，人均 35 动作/关） - **ka59**（中等，人均 104 动作/关） - **cn04**（困难，人均 132 动作/关） **结果** - 两组均通关所有关卡且 RHAE 达 100。 - 规则书版本在三局游戏上动作数均更少：总计 **617 动作** vs. 无规则书 **677 动作**（减少 9%）。 - 智能体迭代轮数（agent turns）降幅更大：总计 **678 轮** vs. **830 轮**（减少 18%），表明持久规则书加速了可执行模型的有效收敛（见表 3）。 ### 3. 种群扩展实验 为检验并行维护多模型的效果，论文在 **wa30**（25 个游戏中人类动作基线最大者，共 9 关）上对比 **$N=1$** 与 **$N=2$**。 **实验设置** - 仅改变保留的模型对数量，其余设置与单模型实验保持一致。 - 两模型共享交互历史，通过通信机制同步实际动作与真实转移。 **结果** - 两种设置均通关全部 9 关且 RHAE 为 100。 - $N=2$ 种群将总动作数从 **899** 降至 **597**（0.66 倍），其中 8/9 个单关动作数持平或更优；两模型从初始不同假设出发，随共享历史累积而逐步收敛（见表 4）。 ### 4. Atari Pong 案例研究 为验证同一学习机制能否支持**反馈控制**（而非仅离散规划），论文在 Atari Pong 上训练基于世界模型的控制器。 **实验设置** - 环境使用 ALE [3]，frame-skip 为 4。 - 智能体通过交互持续修订规则书与可执行动力学模型（包括球轨迹、拍子弹跳、对手行为）。 - 控制器在每次决策前重放近期帧与动作以重建当前状态（球速、对手相位等），并基于模型预测选择动作，**执行阶段无需任何 LLM 调用**。 - 学习持续至控制器取得 21:0 胜利后停止。 - 在 **3 个不同开局**的独立 episode 中评估固定控制器。 **对比基线** - **同 LLM、无世界模型**：每帧调用一次 LLM 进行链式思考，无持久记忆。 - **随机策略**。 - **Model-free RL**：GDI [11]、LASER [34]、IMPALA [9]、Rainbow [15]。 - **Model-based RL**：EfficientZero [46]、EfficientZero V2 [44]。 - **人类平均水平**。 **结果** - 学习后的控制器在 **3/3 个评估 episode 中均以 21:0 获胜**，达到最大单局得分 21。 - **学习成本**为 **9,504 个模拟器帧**（约 $9.5 \times 10^3$），远低于 model-free RL 基线的 $2.0 \times 10^8$ 帧与 model-based RL 基线的 $4.0 \times 10^5$ 帧。 - 无世界模型的直接 LLM 智能体得分为 −19，随机策略约为 −20（见表 5、图 8）。 - 规则书修订过程被完整记录：初始的“四段式弹跳”假设被中心水平回球证伪，进而修正为带中心零偏转的线性公式，最终由后续观测细化为**非对称、有上限的拍面分段映射**（见图 9）。

Q5: 有什么可以进一步探索的点？

基于论文所提出的 Code as Model 框架及其实验结果，以下几个方向值得进一步探索： ### 1. 理论深化：从 LLM 启发式到形式化推理 论文将规则书–可执行程序的选择建模为最小描述长度（MDL）问题： $$(\psi_t, \theta_t) \approx \arg\min_{(\psi,\theta)\in V_t} \big[L(\psi) + L(\theta \mid \psi)\big]$$ 然而当前实现依赖冻结 LLM 的 **SimplifyLLM** 算子来近似这一选择。未来可探索： - 在规则书空间 $\Psi$ 上建立更严格的**贝叶斯先验**与**后验更新**，利用程序综合（program synthesis）或约束求解替代纯 LLM 采样，以获取可证明最优或近似最优的假设。 - 分析版本空间（version space）的紧致边界：在何种交互复杂度下，有限的历史 $H_t$ 足以将候选模型集合 $V_t$ 收缩到唯一解（或 $\epsilon$-等价类）。 ### 2. 种群扩展的系统性研究 论文仅在 **wa30** 上验证了 $N=2$ 的种群，并观察到动作效率提升。更广泛的探索包括： - **尺度效应**：研究随着 $N$ 增大，种群多样性收益与验证/修复开销之间的权衡关系。 - **结构化采样**：当前按行为等价类均匀采样，可尝试基于**预测分歧度**或**信息增益**的主动采样，优先选择能最大程度消除版本空间歧义的模型。 - **种群间的规则迁移**：不同成员可能学习到部分共享的子规则（如“碰撞反弹”），设计机制提取并复用这些公共子结构，而非让每个成员独立维护完整规则书。 ### 3. 从确定性到随机性与连续环境 论文在确定性 POMDP 设定下展开（$T: S \times A \to S$），且 ARC-AGI-3 与 Pong 均具有确定或近似确定的动力学。进一步工作可拓展至： - **随机转移**：将规则书中的转移规则改写为概率性陈述，可执行程序实现为生成模型或概率模拟器，此时精确重放（exact replay）需被**统计一致性检验**（如假设检验或似然比检验）替代。 - **高维连续控制**：Pong 是低维离散动作任务，将该框架应用于连续动作空间（如机器人操作、物理模拟）需要规则书描述连续动力学（如微分约束），并配合相应的数值积分编译策略。 ### 4. 编译与验证机制的增强 当前编译器 $C_\phi$ 与忠实性检查 $\theta \in [\![\psi]\!]$ 均依赖 LLM，存在语义模糊与计算开销： - **形式化验证**：引入符号执行或类型系统，确保规则书到代码的编译满足形式化规约，减少对 LLM 语义判断的依赖。 - **可执行安全性**：论文假设程序终止，但在开放代码生成中可能存在无限循环或副作用。可探索沙箱化执行与资源限制，或构造**全函数式/全可终止**的中间表示。 - **增量编译**：当前规则修订可能触发完整重编译，研究**增量更新**策略（仅修改受规则变更影响的代码分支）可显著降低迭代延迟。 ### 5. 跨任务与跨领域的规则迁移 论文中规则书在单款 ARC-AGI-3 游戏内跨关卡持续更新，但未涉及**跨游戏迁移**： - **规则库（Rule Library）**：维护一个全局的规则片段库，当进入新环境时，智能体先从库中检索并实例化相关动力学模板（如“重力下落”“反弹”“钥匙–门”），再通过交互细化，而非从零开始学习。 - **元规则学习**：学习“如何编写规则书”的元策略，即利用 LLM 的先验知识在不同环境间快速初始化更准确的初始假设，减少冷启动交互量。 ### 6. 与神经世界模型的融合 论文的可执行程序 $\theta$ 是纯符号/代码表示，与基于梯度的神经世界模型形成互补： - **混合表示**：用神经网络处理高维感知（如视觉特征提取），用规则书–代码建模高层逻辑与因果规则，二者通过可微分或符号接口耦合。 - **神经引导的规则归纳**：利用神经网络的注意力机制识别状态转移中的关键对象关系，自动生成候选规则书条目，再经编译与重放验证。 ### 7. 人机协同与可解释性干预 规则书 $\psi$ 作为自然语言显式记忆，天然适合人类理解： - **人类在环修正**：允许专家直接编辑规则书或否决特定规则修订，观察人类反馈如何影响后续编译与规划。 - **可解释性审计**：利用 Git 版本控制保留的完整学习轨迹，逆向分析智能体在特定时刻为何采纳或放弃某条规则，为 AI 安全与错误诊断提供透明链路。 ### 8. 样本效率与计算成本的优化 论文指出每次实验运行涉及“ substantial time and monetary cost ”： - **轻量级 LLM 后端**：研究是否可用更小规模的模型（如经过微调的 7B/13B 模型）替代 Claude Opus 5 进行规则书修订，通过蒸馏将大模型的规则归纳能力压缩到高效小模型中。 - **并行验证**：对种群成员或候选编译结果的 replay 验证进行向量化/批量化，降低 wall-clock 时间。

Q6: 总结一下论文的主要内容

论文提出 **MEMENTO 3**，一种面向冻结大语言模型（frozen LLM）智能体的模型侧递归自我改进（Recursive Self-Improvement, RSI）框架。其核心是 **Code as Model** 设计：智能体通过外部记忆持续构建、验证并修订显式世界模型，在完全不更新底层 LLM 参数的前提下，自主推断陌生环境的动力学规则并指导规划与探索。 ### 1. 核心问题 智能体进入未知环境时，既不了解对象与动力学，也不清楚成功标准。有限交互通常支持多个相互竞争的环境假设（版本空间），单一假设可能因自确认偏差而永远无法被证伪。此前工作多聚焦于策略记忆（“该做什么”），而本文关注**语义世界模型记忆**（“世界如何运转”）的持续学习。 ### 2. Code as Model 架构 智能体的外部学习状态由三部分组成： $$Z_t = (H_t, \psi_t, \theta_t)$$ - **$H_t$**：交互历史（动作–观察记录）。 - **$\psi_t$（Rulebook）**：自然语言规则书，作为持久语义记忆，显式记录智能体对实体、动作语义、动力学、目标及未知替代假设的信念。 - **$\theta_t$（Executable）**：由规则书编译而来的可执行程序（如 Python 模块），实现内部状态空间 $\hat{S}_\theta$、转移函数 $f_\theta$、观察渲染 $\rho_\theta$ 与目标集合 $\hat{G}_\theta$，用于预测、重放验证与规划。 两者互补：规则书承载可泛化的、可人工解读的规则假设；可执行代码将这些假设操作化，为规划器提供确定性模拟。 ### 3. 五阶段持续反思学习循环 交互每前进一步，系统即触发更新算子 $U$： 1. **观察（Observation）**：记录新动作–观察对，扩展 $H_{t+1}$。 2. **反思（Reflection）**：LLM 诊断预测误差来源，选择策略：保留模型、修订规则书，或仅修复代码实现。 3. **规则修订（Rule Revision）**：若规则理解有误，LLM 修改 $\psi_t$ 以显式记录新的环境假设。 4. **编译（Compilation）**：LLM 将（候选）规则书编译为候选可执行程序 $\tilde{\theta}_{t+1}$。 5. **验证（Verification）**：候选对必须同时通过两项检查方可被接受： - **精确重放（Exact Replay）**：用 $\tilde{\theta}_{t+1}$ 从初始观察重放全部历史动作，要求预测的每个下一观察 $\hat{o}_\theta(H_i, a_i)$ 与真实记录 $o_{i+1}$ 完全一致。 - **规则书忠实性（Rulebook Fidelity）**：LLM 评估代码是否忠实实现自然语言规则，即 $\theta \in [\![\psi]\!]$。 通过验证的模型对用于重建当前内部状态 $\hat{s}_{\theta_t}(H_t)$，并支持后续最短路径规划。 ### 4. 种群扩展（Population Extension） 为避免单一模型陷入自确认回路，系统可并行维护 $N$ 个通过验证的规则书–可执行程序对： $$\Phi_t = \{(\psi_t^i, \theta_t^i)\}_{i=1}^N \subseteq V_t$$ 所有成员共享同一交互历史 $H_t$。行动选择时按**行为等价类**均匀采样不同计划；新观察同时检验所有成员，预测冲突者进入修复。该设计保留探索多样性，降低对单一随机初始假设的依赖。$N=1$ 退化为单模型设定。 ### 5. 实验结果 - **ARC-AGI-3**：单模型（$N=1$）在全部 **25 个公开游戏** 的 **183 个关卡** 上全部通关，达到 **RHAE 100.0**（上限），总计使用 **7,518** 个动作，仅为人类基线（17,135）的 **44%**。相较之下，baseline1 为 99.0 分（8,347 动作），其余基线存在未通关游戏。 - **消融实验**：移除自然语言规则书后，在三款不同难度游戏上动作数增加 9%，智能体迭代轮数增加 18%，表明规则书显式记忆显著加速收敛。 - **种群扩展**：在 wa30（9 关）上将 $N$ 从 1 增至 2，总动作数从 899 降至 597（0.66 倍），8/9 个单关效率持平或提升。 - **Atari Pong**：同一学习机制支持连续反馈控制。学习后的控制器在 **3 个不同开局** 的评估中均以 **21:0** 获胜，且执行阶段无需任何 LLM 调用。学习成本仅 **9,504 模拟器帧**，远低于 model-free RL（$2.0\times10^8$ 帧）与 model-based RL（$4.0\times10^5$ 帧）基线。 ### 6. 主要贡献 - 将 Memento 系列的反思记忆从策略/程序记忆扩展到**显式语义世界模型记忆**，以自然语言规则书与可执行代码的双组件形式实现。 - 提出并验证了一种**基于模型的递归自我改进路径**：智能体利用自身构建的世界模型指导交互与探索，产生的证据反过来修订该模型，形成自主改进闭环。 - 在 ARC-AGI-3 上达到人类动作效率上限，并在 Atari Pong 上展示了从规则书学习到零 LLM 调用反馈控制的跨域适用性。
